# Dots — Plan 3b: The Six Screens Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the placeholder page with the six screens of the Dots desktop app (Dots, dot editor, run view, Inbox, Chat, Settings) on top of the Plan 3a command and event layer, with the small core and app changes the screens need.

**Architecture:** The UI is a React app under `ui/` that talks to the Rust side only through `ui/src/api` (typed command wrappers and event listeners). TanStack Query holds every answer; one hook subscribes to the runtime's events and patches or invalidates the caches, so nothing polls. A hash router maps six routes onto six screen components inside one frame (sidebar, banners, toasts). Every command answer and event payload is parsed with a strict zod schema before a component sees it. The core gains four small behaviours (settings saves keep the pause and the tested version, runs announce their workspace, no webhook URL without the server, untrimmed patches) and the app crate gains a native confirmation for a new Claude program plus two read-only commands.

**Tech Stack:** Rust 1.95, Tauri 2.12 with tauri-plugin-dialog 2.8; Bun 1.3, Vite 8.3, React 19.3, TypeScript 6.0 (strict), Tailwind CSS 4.3, shadcn/ui (CLI 4.21, `radix-nova` style) on radix-ui 1.8, TanStack Query 5.104, react-router 8.4, react-markdown 10.1, zod 4.6, Vitest 5.0 with Testing Library and jsdom 30.

**Spec:** `docs/superpowers/specs/2026-10-08-dots-design.md` — §7 UI, §12 "UI (3b)", "Tauri shell" (the `cancelled` kind, the native confirmation, `update_settings`), §8 rows "Port in use" and "Runtime fails to start". Amended for this plan in commit `325db8c`.

**Plan 3 is split in three.** 3a (core additions, Tauri shell, command and event surface) is PR #2, branch `feat/app`. This is **3b**. **3c** adds the Windows Job Object, the hardening items of spec §12, the full manual smoke and the NSIS installer.

**Previous plans:** `docs/superpowers/plans/2026-10-08-dots-core.md` (Plan 1), `docs/superpowers/plans/2026-10-09-dots-local-engine.md` (Plan 2), `docs/superpowers/plans/2026-10-09-dots-app-3a.md` (Plan 3a).

## Review Focus

1. **A Settings form that undoes what happened elsewhere** — the tray paused schedules, or the CLI was marked as tested, after the form loaded its copy; saving the form must not undo either. → Task 1 `saving_settings_keeps_the_pause_and_the_tested_version`.
2. **The webview pointing Dots at another program on its own** — a new `claude_path` must need the user's yes in a native dialog, a declined dialog must save nothing, and the bypass must exist only in debug builds. → Task 2 `only_a_new_program_needs_confirmation`, `only_debug_builds_take_the_answer_from_the_environment`; Task 10 "says that nothing was saved when the native confirmation is declined".
3. **A backend and a UI of different versions** — an answer or event in a shape the UI does not know must fail loudly or trigger a refetch, never render half-parsed data, and an unknown engine event must stay visible. → Task 2 "knows every … the core has"; Task 3 "refuses an answer in a shape it does not know", "asks for a refetch when a runtime event is in a shape it does not know"; Task 7 "keeps what it cannot read as raw instead of dropping it".
4. **Model-written text taking over the window** — a link that navigates the app, an image that calls out, raw HTML or a script in a transcript. → Task 7 "renders model text without live links, images or raw HTML".
5. **A destructive click that goes through, or is offered where it cannot work** — discard, delete and regenerate must ask first; a folder-mode run must offer no discard and no diff; a running thread no review. → Task 6 "deletes the dot only after a confirmation"; Task 7 "discards the worktree only after a confirmation that names the branch", "has no changes tab, discard or review for a folder run that succeeded"; Task 8 "discards a worktree only after a confirmation".

```rust
async fn a_worktree_run_announces_its_workspace_while_it_runs() {
    let t = start().await;
    let mut events = t.rt.subscribe();
    let run = edited_run(&t).await;
    let mut announced = false;
    while let Ok(event) = events.try_recv() {
        if let RuntimeEvent::RunUpdated { run: seen } = event {
            announced |= seen.id == run.id
                && seen.status == RunStatus::Running
                && seen.branch == run.branch
                && seen.workspace_path == run.workspace_path;

    }
```

```rust
//! Native confirmations for changes the webview must not make on its own (spec §12).

use tauri::{AppHandle, Manager};
use tauri_plugin_dialog::{DialogExt, MessageDialogButtons, MessageDialogKind};

/// Debug builds accept `DOTS_CONFIRM=yes` in place of the dialog, so a smoke run can change
/// the Claude program without a person at the screen. Release builds always ask.
pub const CONFIRM_ENV: &str = "DOTS_CONFIRM";

/// The program a settings change would make Dots run as the Claude CLI, when that needs the
/// user's confirmation: a non-empty `claude_path` that differs from the stored one. Clearing
/// the path (back to searching `PATH`) and saving it unchanged need none.
pub fn claude_program_to_confirm(current: Option<&str>, next: Option<&str>) -> Option<String> {
    let next = next.map(str::trim).filter(|p| !p.is_empty())?;
    (current.map(str::trim) != Some(next)).then(|| next.to_string())
}

pub fn claude_program_message(program: &str) -> String {
    format!(
        "Dots will run this program as the Claude CLI from the next start:\n\n{program}\n\n\
         Allow this only for a program you trust."
    )
}

/// Whether the environment answers confirmations instead of the user.
pub fn preconfirmed(debug_build: bool, env: Option<&str>) -> bool {
    debug_build && env == Some("yes")
}

/// Asks in a native dialog, which the webview cannot answer. `false` when declined or closed.
pub async fn ask(app: &AppHandle, title: &str, message: String) -> bool {
    let env = std::env::var(CONFIRM_ENV).ok();
    if preconfirmed(cfg!(debug_assertions), env.as_deref()) {
        tracing::warn!("{CONFIRM_ENV}=yes: confirmed without a dialog: {title}");
        return true;
    }
    let (tx, rx) = tokio::sync::oneshot::channel();
    let mut dialog = app
        .dialog()
        .message(message)
        .title(title)
        .kind(MessageDialogKind::Warning)
        .buttons(MessageDialogButtons::OkCancelCustom(
            "Allow".into(),
            "Cancel".into(),
        ));
    if let Some(window) = app.get_webview_window("main") {
        dialog = dialog.parent(&window);
    }
    dialog.show(move |allowed| {
        let _ = tx.send(allowed);
    });
    rx.await.unwrap_or(false)
}
```

```ts
export function toCommandError(e: unknown): CommandError {
  const parsed = T.CmdError.safeParse(e);
  if (parsed.success) return new CommandError(parsed.data.kind, parsed.data.message);
  if (e instanceof Error) return new CommandError("internal", e.message);
  // An error object with a kind this UI does not know still carries its message.
  const message =

async function call<S extends z.ZodType>(
  schema: S,
  cmd: string,
  args?: InvokeArgs,

    const at = issue.path.join(".") || "the answer";
    throw new CommandError("internal", `${cmd}: unexpected ${at}: ${issue.message}`);
  }
  return parsed.data;
}
```

```ts
import { listen, type UnlistenFn } from "@tauri-apps/api/event";
import { z } from "zod";

import * as T from "./types";
import type { RuntimeEvent, Status } from "./types";

function parse<S extends z.ZodType>(event: string, schema: S, payload: unknown) {
  const parsed = schema.safeParse(payload);
  if (parsed.success) return parsed.data;
  console.error(`event "${event}" in a shape this UI does not know`, parsed.error.issues[0]);
  return undefined;
}

/// Every runtime event. `onInvalid` is called for an event in a shape this UI does not know:
/// the caller cannot patch its caches from it, so it should refetch, as after `onLagged`.
export function onRuntimeEvent(
  handler: (event: RuntimeEvent) => void,
  onInvalid: () => void = () => {},
): Promise<UnlistenFn> {
  return listen("runtime", (e) => {
    const event = parse("runtime", T.RuntimeEvent, e.payload);
```

```ts
// A stand-in for the Rust side in component tests: commands answer from handlers the test
// installs, and the test emits events. Wired in by test/setup.ts.
type Handler = (args: Record<string, unknown>) => unknown;
type Listener = (event: { payload: unknown }) => void;

class FakeBackend {
  private handlers = new Map<string, Handler>();
  private listeners = new Map<string, Set<Listener>>();
  /// Every command invoked, in order, with its arguments.
  calls: [string, Record<string, unknown>][] = [];

  /// Answers `cmd` with what `handler` returns; a thrown value rejects the command.
  on(cmd: string, handler: Handler): void {
    this.handlers.set(cmd, handler);
  }

  /// The arguments of every call to `cmd`.
  callsTo(cmd: string): Record<string, unknown>[] {
    return this.calls.filter(([name]) => name === cmd).map(([, args]) => args);
  }

  emit(event: string, payload: unknown): void {
    for (const listener of this.listeners.get(event) ?? []) listener({ payload });
  }

  reset(): void {
    this.handlers.clear();
    this.listeners.clear();
    this.calls = [];
  }

  async invoke(cmd: string, args: Record<string, unknown> = {}): Promise<unknown> {
    this.calls.push([cmd, args]);
    const handler = this.handlers.get(cmd);
    if (!handler) throw { kind: "internal", message: `the test has no answer for ${cmd}` };
    return handler(args);
  }

  async listen(event: string, listener: Listener): Promise<() => void> {
    const set = this.listeners.get(event) ?? new Set();
    this.listeners.set(event, set);
    set.add(listener);
    return () => set.delete(listener);
  }
}

export const backend = new FakeBackend();
```

```ts
const dateTime = new Intl.DateTimeFormat(undefined, { dateStyle: "medium", timeStyle: "short" });

/// An RFC 3339 timestamp in the user's locale and time zone. "" for none; the text itself
/// when it is not a timestamp.
export function localDateTime(iso: string | null | undefined): string {
  if (!iso) return "";
  const t = Date.parse(iso);
  return Number.isNaN(t) ? iso : dateTime.format(t);
}

/// "45s", "3m 05s", "2h 07m". Without an end the run is still going: measured up to `now`.
export function duration(
  startIso: string | null,
  endIso: string | null,
  now: number = Date.now(),
): string {
  if (!startIso) return "";
  const ms = (endIso ? Date.parse(endIso) : now) - Date.parse(startIso);
  if (!Number.isFinite(ms) || ms < 0) return "";
  const s = Math.floor(ms / 1000);
  const pad = (n: number) => String(n).padStart(2, "0");
  if (s < 60) return `${s}s`;
  if (s < 3600) return `${Math.floor(s / 60)}m ${pad(s % 60)}s`;
  return `${Math.floor(s / 3600)}h ${pad(Math.floor((s % 3600) / 60))}m`;
}

/// "just now", "5 min ago", "3 h ago", "2 d ago", and "in 5 min" for a time ahead.
export function relativeTime(iso: string | null | undefined, now: number = Date.now()): string {
  if (!iso) return "";
  const t = Date.parse(iso);
  if (Number.isNaN(t)) return "";
  const ahead = t > now;
  const ms = Math.abs(t - now);
  if (ms < 45_000) return ahead ? "now" : "just now";
  const [n, unit] =
    ms < 3_600_000
      ? [Math.round(ms / 60_000), "min"]
      : ms < 86_400_000
        ? [Math.round(ms / 3_600_000), "h"]
        : [Math.round(ms / 86_400_000), "d"];
  return ahead ? `in ${n} ${unit}` : `${n} ${unit} ago`;
}
```

```ts
/// the backend tells the UI when something changed, so nothing polls.
export function createQueryClient(): QueryClient {
  return new QueryClient({
    defaultOptions: {

    },

export const keys = {
  startupError: ["startup-error"] as const,
  status: ["status"] as const,
  settings: ["settings"] as const,
  overview: ["overview"] as const,
  inbox: ["inbox"] as const,
  dot: (id: string) => ["dot", id] as const,
  runs: (dotId: string | null) => ["runs", dotId] as const,
  run: (id: string) => ["run", id] as const,
  thread: (runId: string) => ["thread", runId] as const,
  events: (runId: string) => ["events", runId] as const,
  approvals: (runId: string) => ["approvals", runId] as const,
  diff: (runId: string) => ["diff", runId] as const,
};

/// `have` plus the events of `more` it does not hold yet, ordered by `seq`.
export function mergeEvents(have: RunEventRecord[], more: RunEventRecord[]): RunEventRecord[] {
  const seen = new Set(have.map((e) => e.seq));
  const fresh = more.filter((e) => !seen.has(e.seq));
  if (fresh.length === 0) return have;
  return [...have, ...fresh].sort((a, b) => a.seq - b.seq);
}

/// A run's events. A refetch asks only for what is missing: the events after the last one
/// already loaded.
export function eventsQuery(qc: QueryClient, runId: string) {
  const queryKey = keys.events(runId);
  return {
    queryKey,
    queryFn: async () => {
      const have = qc.getQueryData<RunEventRecord[]>(queryKey) ?? [];
      const more = await commands.listRunEvents(runId, have.at(-1)?.seq ?? 0);
      return mergeEvents(have, more);
    },
  };
```

```ts
import { useQueryClient, type QueryClient } from "@tanstack/react-query";
import { useEffect } from "react";
import { useNavigate } from "react-router";

import { onLagged, onNavigate, onRuntimeEvent, onStatus } from "@/api/events";
import type { RunEventRecord, RuntimeEvent } from "@/api/types";
import { keys, mergeEvents } from "@/lib/query";

/// Brings the query caches in step with one runtime event.
export function applyRuntimeEvent(qc: QueryClient, event: RuntimeEvent): void {
  switch (event.type) {
    case "run_updated":
      qc.setQueryData(keys.run(event.run.id), event.run);
      // Lists and views a run shows up in. The prefixes cover every dot's and thread's key.
      for (const queryKey of [["thread"], ["runs"], ["diff"], keys.overview, keys.inbox]) {
        void qc.invalidateQueries({ queryKey });
      }
      break;
    case "run_event": {
      const queryKey = keys.events(event.event.run_id);
      // Only a list that is loaded is extended; one that is not loads in full when asked for.
      if (qc.getQueryData(queryKey) !== undefined) {
        qc.setQueryData<RunEventRecord[]>(queryKey, (have = []) =>
          mergeEvents(have, [event.event]),
        );
      }
      break;
    }
    case "approval_requested":
    case "approval_decided":
      void qc.invalidateQueries({ queryKey: keys.inbox });
      void qc.invalidateQueries({ queryKey: keys.approvals(event.approval.run_id) });
      break;
  }
}

/// Subscribes the app to the backend: runtime events patch the caches, a lagged or unreadable
/// stream refetches everything, the tray navigates, and a status changed elsewhere is taken.
export function useRuntimeEvents(): void {
  const qc = useQueryClient();
  const navigate = useNavigate();
  useEffect(() => {
    const refetch = () => void qc.invalidateQueries();
    const subscriptions = [
      onRuntimeEvent((event) => applyRuntimeEvent(qc, event), refetch),
      onLagged(refetch),
      onNavigate((path) => void navigate(path)),
      onStatus((status) => qc.setQueryData(keys.status, status)),
    ];
    return () => {
      for (const s of subscriptions) void s.then((unlisten) => unlisten());
    };
  }, [qc, navigate]);
}
```

```tsx
  if (schedulesPaused) return "Paused";
  return localDateTime(row.next_fire) || "Not scheduled";
```

```ts
describe("dot editor rules", () => {

    expect(specErrors(good, "")).toEqual({});

      expect(specErrors({ ...good, name }, "").name, name).toBeDefined();
    }
    for (const name of ["a", "nightly-tests_2", "x".repeat(64)]) {
      expect(specErrors({ ...good, name }, "").name, name).toBeUndefined();
    }
  });

    expect(specErrors({ ...local, endpoint_url: null }, "").endpoint_url).toMatch(/needs its/);
    expect(specErrors({ ...local, endpoint_url: "https://x" }, "").endpoint_url).toMatch(/https/);

    expect(specErrors({ ...good, endpoint_url: null }, "")).toEqual({});
  });

    const bad = { max_turns: 0, timeout_secs: 604801, approval_wait_secs: 281 };

    expect(specErrors({ ...good, timeout_secs: 1.5 }, "").timeout_secs).toBeDefined();
  });
```

```ts
// The dot editor's checks. They mirror `DotSpec::validate` in the core (model.rs) so most
// mistakes show next to their field before a save; the core still has the last word.
import { z } from "zod";

import { LIMITS, type DotSpec } from "@/api/types";

export type SpecErrors = Partial<Record<keyof DotSpec, string>>;

const filled = (message: string) => z.string().refine((s) => s.trim() !== "", message);
const whole = (min: number, max: number, message: string) =>
  z.number({ error: message }).int(message).min(min, message).max(max, message);

const Fields = z.object({
  name: z.string().regex(/^[A-Za-z0-9_-]{1,64}$/, "Use 1 to 64 letters, digits, '-' or '_'."),
  instructions: filled("Say what the dot should do."),
  model: filled("Name the model to use."),
  workdir: filled("Choose the folder the dot works in."),
  max_turns: whole(1, Number.MAX_SAFE_INTEGER, "Max turns must be a whole number, 1 or more."),
  timeout_secs: whole(
    1,
    LIMITS.max_timeout_secs,
    `Timeout must be a whole number of seconds, 1 to ${LIMITS.max_timeout_secs} (7 days).`,
  ),
  approval_wait_secs: whole(
    0,
    LIMITS.max_approval_wait_secs,
    `Approval wait must be a whole number of seconds, 0 to ${LIMITS.max_approval_wait_secs}.`,
  ),
});

/// The MCP servers a text field holds. An empty field is "none".
export function parseMcp(
  text: string,
): { value: Record<string, unknown> | null } | { error: string } {
  if (text.trim() === "") return { value: null };
  let parsed: unknown;
  try {
    parsed = JSON.parse(text);
  } catch {
    return { error: "This is not valid JSON." };
  }
  if (typeof parsed !== "object" || parsed === null || Array.isArray(parsed)) {
    return { error: "Write a JSON object: server name, then its configuration." };
  }
  if ("dots" in parsed) return { error: "The server name 'dots' is reserved." };
  return { value: parsed as Record<string, unknown> };
}

/// What is wrong with a draft, by field. Empty when it can be saved.
export function specErrors(spec: DotSpec, mcpText: string): SpecErrors {
  const errors: SpecErrors = {};
  const fields = Fields.safeParse(spec);
  if (!fields.success) {
    for (const issue of fields.error.issues) {
      errors[issue.path[0] as keyof DotSpec] ??= issue.message;
    }
  }
  if (spec.engine === "local") {
    const url = (spec.endpoint_url ?? "").trim();
    if (url.startsWith("https://")) {
      errors.endpoint_url = "Use http://. https is not supported for local endpoints.";
    } else if (!/^http:\/\/[^\s/]+/.test(url)) {
      errors.endpoint_url = "A local dot needs its endpoint, starting with http://.";
    }
  }
  if (spec.policy.rules.some((r) => r.tool.trim() === "")) {
    errors.policy = "Every rule needs a tool pattern.";
  }
  const mcp = parseMcp(mcpText);
  if ("error" in mcp) errors.mcp_servers = mcp.error;
  return errors;
}

/// The editable part of a stored dot.
export function specOf(dot: DotSpec): DotSpec {
  return {
    name: dot.name,
    instructions: dot.instructions,
    engine: dot.engine,
    model: dot.model,
    endpoint_url: dot.endpoint_url,
    workdir: dot.workdir,
    workspace_mode: dot.workspace_mode,
    schedule: dot.schedule,
    policy: dot.policy,
    mcp_servers: dot.mcp_servers,
    use_user_settings: dot.use_user_settings,
    max_turns: dot.max_turns,
    timeout_secs: dot.timeout_secs,
    approval_wait_secs: dot.approval_wait_secs,
    enabled: dot.enabled,
  };
}
```

```ts
/// `value`, once it has stopped changing for `ms`.
export function useDebounced<T>(value: T, ms: number): T {
  const [settled, setSettled] = useState(value);
  useEffect(() => {
    const timer = setTimeout(() => setSettled(value), ms);
    return () => clearTimeout(timer);
  }, [value, ms]);
  return settled;
}
```

```tsx
function draftOf(spec: DotSpec): Draft {
  return {

/// The form with its Save button. `onSave` stores the spec; its rejection is shown above the
/// form (the core's answer when it refuses what the form let through).
function Editor(props: {
  title: string;
  initial: DotSpec;
  existing: Dot | null;
  saveLabel: string;
  onSave: (spec: DotSpec) => Promise<unknown>;
  actions?: ReactNode;
  children?: (form: ReactNode) => ReactNode;
}) {
  const [draft, setDraft] = useState(() => draftOf(props.initial));
  const [tried, setTried] = useState(false);
  const settings = useQuery({ queryKey: keys.settings, queryFn: commands.getSettings }).data;
  const save = useMutation({ mutationFn: props.onSave });

  // The core validates the cron expression and computes the preview; the UI parses no cron.
  const expr = useDebounced((draft.spec.schedule ?? "").trim(), 300);
  const preview = useQuery({
    queryKey: ["schedule-preview", expr],
    queryFn: () => commands.previewSchedule(expr, 3),
    enabled: expr !== "",
  });

  const errors = specErrors(draft.spec, draft.mcpText);
  if (expr !== "" && preview.isError) errors.schedule = errorMessage(preview.error);

  function submit() {
    setTried(true);
    if (Object.keys(errors).length > 0) return;
    const mcp = parseMcp(draft.mcpText);
    save.mutate({
      ...draft.spec,
      schedule: draft.spec.schedule?.trim() || null,
      endpoint_url: draft.spec.endpoint_url?.trim() || null,
      mcp_servers: "value" in mcp ? mcp.value : null,
    });
  }

  const form = (
    <div className="flex flex-col gap-4">
      {save.isError && <ErrorNote error={save.error} />}
      {tried && Object.keys(errors).length > 0 && (
        <p role="alert" className="text-destructive">
          Fix the marked fields, then save again.
        </p>
      )}
      <DotForm
        draft={draft}
        onChange={setDraft}
        // Until the first save attempt only the schedule's error shows: the core reports it
        // while the user types, and an empty new form should not start out red.
        errors={tried ? errors : errors.schedule ? { schedule: errors.schedule } : {}}
        existing={props.existing}
        endpoints={settings?.local_endpoints ?? []}
        schedule={{
          times: expr !== "" && preview.data ? preview.data : [],
          pending: preview.isFetching,
        }}
      />
    </div>
  );
  return (
    <Page
      title={props.title}
      actions={
        <>
          {props.actions}
          <Button size="sm" disabled={save.isPending} onClick={submit}>
            {props.saveLabel}
          </Button>
        </>
      }
    >
      {props.children ? props.children(form) : form}
    </Page>
  );
}
```

```ts
// Turns a run's stored events into what the transcript shows.
import { RunEventData, type RunEventRecord } from "@/api/types";

export type TranscriptItem =
  | { type: "text"; seq: number; text: string }
  | {
      type: "tool";
      seq: number;
      tool: string;
      input: unknown;
      /// `null` until the result arrives.
      result: { output: string; isError: boolean } | null;
    }
  | { type: "error"; seq: number; text: string }
  /// Something the transcript does not render as conversation; shown collapsed.
  | { type: "raw"; seq: number; label: string; text: string };

/// One line that says what a tool call is about.
export function toolPreview(input: unknown): string {
  if (typeof input === "object" && input !== null) {
    for (const key of ["command", "file_path", "path", "pattern", "url"]) {
      const value = (input as Record<string, unknown>)[key];
      if (typeof value === "string") return value;
    }
  }
  const text = JSON.stringify(input) ?? "";
  return text.length > 80 ? `${text.slice(0, 80)}…` : text;
}

/// Assistant text, tool calls with their results paired by id, failures, and raw lines.
/// Bookkeeping events (session, usage, the local engine's `message` records, the final
/// summary) are left out. An event from a newer core that does not parse is kept as raw.
export function transcriptItems(events: RunEventRecord[]): TranscriptItem[] {
  const items: TranscriptItem[] = [];
  const calls = new Map<string, Extract<TranscriptItem, { type: "tool" }>>();
  for (const record of events) {
    const parsed = RunEventData.safeParse(record.data);
    if (!parsed.success) {
      items.push({
        type: "raw",
        seq: record.seq,
        label: `Unknown event (${record.kind})`,
        text: JSON.stringify(record.data, null, 2) ?? "",
      });
      continue;
    }
    const event = parsed.data;
    switch (event.kind) {
      case "assistant_text":
        items.push({ type: "text", seq: record.seq, text: event.text });
        break;
      case "tool_call": {
        const call = {
          type: "tool" as const,
          seq: record.seq,
          tool: event.tool,
          input: event.input,
          result: null,
        };
        calls.set(event.id, call);
        items.push(call);
        break;
      }
      case "tool_result": {
        const result = { output: event.output, isError: event.is_error };
        const call = calls.get(event.id);
        if (call) call.result = result;
        else items.push({ type: "raw", seq: record.seq, label: "Tool result", text: event.output });
        break;
      }
      case "failed":
        items.push({ type: "error", seq: record.seq, text: event.error });
        break;
      case "raw":
        items.push({ type: "raw", seq: record.seq, label: "Unparsed output", text: event.line });
        break;
      case "session_started":
      case "usage":
      case "message":
      case "finished":
        break;
    }
  }
  return items;
}
```

```ts
import { useEffect, useState } from "react";

/// The current time, refreshed every second while `ticking`, so that the duration of a run
/// that is still going counts up on screen.
export function useNow(ticking: boolean): number {
  const [now, setNow] = useState(() => Date.now());
  useEffect(() => {
    if (!ticking) return;
    const timer = setInterval(() => setNow(Date.now()), 1000);
    return () => clearInterval(timer);
  }, [ticking]);
  return now;
}
```

```tsx
import type { FileDiff, WorktreeDiff } from "@/api/types";
import { Badge } from "@/components/ui/badge";

function lineClass(line: string): string {
  if (line.startsWith("@@")) return "text-sky-300";
  if (line.startsWith("+")) return "bg-emerald-500/15 text-emerald-200";
  if (line.startsWith("-")) return "bg-red-500/15 text-red-200";
  if (line.startsWith("\\")) return "text-muted-foreground italic";
  return "";
}

/// The hunks of a patch: everything from the first `@@` line on. The header lines above it
/// repeat what the file's row already says.
export function hunkLines(patch: string): string[] {
  const lines = patch.split("\n");
  if (lines.at(-1) === "") lines.pop();
  const first = lines.findIndex((l) => l.startsWith("@@"));
  return first === -1 ? [] : lines.slice(first);
}

function File({ file }: { file: FileDiff }) {
  const lines = hunkLines(file.patch);
  return (
    <details open className="rounded-md border">
      <summary className="flex cursor-pointer items-center gap-2 px-2 py-1">
        <Badge variant="secondary">{file.status}</Badge>
        <span className="font-mono text-xs">{file.path}</span>
      </summary>
      {file.binary ? (
        <p className="border-t px-2 py-1 text-xs text-muted-foreground">Binary file.</p>
      ) : lines.length === 0 ? (
        <p className="border-t px-2 py-1 text-xs text-muted-foreground">
          No text changes to show.
        </p>
      ) : (
        <pre className="overflow-x-auto border-t text-xs">
          {lines.map((line, i) => (
            <div key={i} className={`px-2 ${lineClass(line)}`}>
              {line === "" ? " " : line}
            </div>
          ))}
        </pre>
      )}
    </details>
  );
}

/// What a thread changed in its worktree, one collapsible block per file.
export function DiffView({ diff }: { diff: WorktreeDiff }) {
  if (diff.files.length === 0) {
    return <p className="text-muted-foreground">No changes.</p>;
  }
  return (
    <div className="flex flex-col gap-2">
      {diff.truncated && (
        <p role="status" className="rounded-md border border-amber-500/40 bg-amber-500/15 p-2">
          This diff is larger than 1 MiB. Every changed file is listed, but some are shown
          without their changes. Open the folder to see them.
        </p>
      )}
      {diff.files.map((file) => (
        <File key={file.path} file={file} />
      ))}
    </div>
  );
}
```

```ts
import type { Run } from "@/api/types";

/// A chat conversation with a dot: the lineage that starts at a chat run.
export type ChatThread = {
  /// The id of the lineage's first run; it names the thread in the address.
  rootId: string;
  /// The first message, cut to one line.
  title: string;
  /// The lineage's newest run: the thread's state, and what a follow-up continues from.
  latest: Run;
};

function firstLine(run: Run): string {
  const message =
    typeof run.payload === "object" && run.payload !== null
      ? (run.payload as Record<string, unknown>).message
      : null;
  const line = typeof message === "string" ? message.trim().split("\n")[0] : "";
  if (line === "") return "Chat";
  return line.length > 60 ? `${line.slice(0, 60)}…` : line;
}

/// The chat threads among a dot's runs, the most recently active first. Lineages that a
/// schedule, a webhook or "Run now" started are not chats.
export function chatThreads(runs: Run[]): ChatThread[] {
  const threads = new Map<string, ChatThread>();
  const byAge = [...runs].sort((a, b) => a.queued_at.localeCompare(b.queued_at));
  for (const run of byAge) {
    if (run.parent_run_id === null && run.trigger === "chat") {
      threads.set(run.id, { rootId: run.id, title: firstLine(run), latest: run });
    }
  }
  for (const run of byAge) {
    const thread = threads.get(run.root_run_id);
    if (thread) thread.latest = run;
  }
  return [...threads.values()].sort((a, b) =>
    b.latest.queued_at.localeCompare(a.latest.queued_at),
  );
}

export function isActive(run: Run): boolean {
  return run.status === "queued" || run.status === "running" || run.status === "awaiting_approval";
}
```

```tsx
/// What is wrong with the numbers, mirroring `Settings::validate` in the core.
export function settingsErrors(draft: Pick<Settings, "port" | "max_concurrent_runs">): Errors {
  const errors: Errors = {};
  const whole = (n: number, min: number, max: number) => Number.isInteger(n) && n >= min && n <= max;
  if (!whole(draft.port, 1, 65535)) errors.port = "The port must be a whole number, 1 to 65535.";
  if (!whole(draft.max_concurrent_runs, 1, LIMITS.max_concurrent_runs)) {
    errors.max = `Runs at once must be a whole number, 1 to ${LIMITS.max_concurrent_runs}.`;

  return errors;
}
```

### Task 11: Smoke the screens on a debug build

The tests above run against a fake backend in jsdom. This task runs the real app once, with the fake CLI and a temporary data folder, and looks at it. It adds the helper that makes that possible from a terminal.

**Files:**
- Create: `tools/smoke/webview.mjs`

**Interfaces:**
- Consumes: the finished app; `DOTS_DATA_DIR`, `DOTS_CONFIRM` (Task 2), `FAKE_CLAUDE_SCRIPT` (the fake CLI of Plan 1).
- Produces: `node tools/smoke/webview.mjs <port> eval "<expr>" | text | goto <route> | shot <file.png>`. In `eval`, `invoke(name, args)` is the Tauri bridge. A route is written without its leading slash (Git Bash would rewrite `/inbox` into a Windows path). - [ ] **Step 1: The helper**

Create `tools/smoke/webview.mjs`:

```js
// Drives the Dots window from a terminal, for smoke runs without a person at the screen.
// It talks to WebView2's remote-debugging port, which only exists when the app is started
// with WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=<port>.
//
//   node tools/smoke/webview.mjs <port> eval "<async JS expression>"   print its JSON result
//   node tools/smoke/webview.mjs <port> text                           print the visible text
//   node tools/smoke/webview.mjs <port> goto inbox                     open a route (no leading
//                                                                    slash: Git Bash would turn
//                                                                    "/inbox" into a Windows path)
//   node tools/smoke/webview.mjs <port> shot <file.png>                save a screenshot
//
// In `eval`, `invoke` is the Tauri bridge: invoke("status"), invoke("run_now", {dotId}).
// After invoke("restart_app") the page closes before it answers; the script then says so and
// exits with code 1, which is the expected outcome of that one call.
// Needs Node 22 or newer (global fetch and WebSocket).
import { writeFileSync } from "node:fs";

const [port, action, arg] = process.argv.slice(2);
if (!port || !["eval", "text", "goto", "shot"].includes(action)) {
  console.error('usage: webview.mjs <port> eval "<expr>" | text | goto <route> | shot <file.png>');
  process.exit(2);
}

const targets = await (await fetch(`http://127.0.0.1:${port}/json`)).json();
const page = targets.find((t) => t.type === "page");
if (!page) throw new Error(`no page on debugging port ${port}`);
const socket = new WebSocket(page.webSocketDebuggerUrl);
await new Promise((resolve, reject) => {
  socket.onopen = resolve;
  socket.onerror = () => reject(new Error("could not connect to the page"));
});

let lastId = 0;
const waiting = new Map();
socket.onmessage = (message) => {
  const reply = JSON.parse(message.data);
  waiting.get(reply.id)?.(reply);
  waiting.delete(reply.id);
};
// The page goes away when the app restarts or quits: answer what still waits, so the script
// ends instead of hanging.
socket.onclose = () => {
  for (const settle of waiting.values()) settle({ closed: true });
  waiting.clear();
};
const send = (method, params = {}) =>
  new Promise((resolve) => {
    waiting.set(++lastId, resolve);
    socket.send(JSON.stringify({ id: lastId, method, params }));
  });

/// Evaluates an async expression in the page and returns its value (JSON-encoded there).
async function evaluate(expression) {
  const reply = await send("Runtime.evaluate", {
    expression: `(async () => {
      const invoke = window.__TAURI_INTERNALS__.invoke;
      return JSON.stringify(await (async () => (${expression}))());
    })()`,
    awaitPromise: true,
    returnByValue: true,
  });
  if (reply.closed) throw new Error("the page closed before it answered");
  const failure = reply.result?.exceptionDetails;
  if (failure) {
    const thrown = failure.exception?.value ?? failure.exception?.description ?? failure.text;
    throw new Error(`the page threw: ${JSON.stringify(thrown)}`);
  }
  const value = reply.result?.result?.value;
  return value === undefined ? undefined : JSON.parse(value);
}

let exitCode = 0;
try {
  if (action === "eval") {
    console.log(JSON.stringify(await evaluate(arg), null, 2));
  } else if (action === "text") {
    console.log(await evaluate("document.body.innerText"));
  } else if (action === "goto") {
    const route = (arg ?? "").replace(/^#?\/?/, "");
    await evaluate(`(location.hash = ${JSON.stringify(`#/${route}`)}, null)`);
  } else {
    const shot = await send("Page.captureScreenshot", { format: "png" });
    writeFileSync(arg, Buffer.from(shot.result.data, "base64"));
    console.log(`saved ${arg}`);
  }
} catch (error) {
  console.error(error.message);
  exitCode = 1;
}
socket.close();
process.exit(exitCode);
```

Run: `node --check tools/smoke/webview.mjs`
