# Teams and Workflows, Plan A (Core: Teams, Workflow Runs, Guards, start_workflow) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dots keeps teams of dots with projects and workflows, runs a workflow step by step (agent steps in the project's repo, the person's check), keeps each run within its budget, and lets a member start a workflow from a chat with `start_workflow`.
**Architecture:** A workflow is a validated JSON definition (`workflow.rs`) stored per team (`store/teams.rs`, migration 0013). A workflow run copies its definition and project and keeps step runs (`store/workflow_runs.rs`); every dot run of a step carries `workflow_step_run_id`, inherited by the runs that continue it. `workflows::Workflows` is a loop like the follow-ups': each pass reads the workflow runs in flight from the store and moves each one (queue the member's run with a `## Workflow` section, watch it, hand off, wait at a check, wait at a limit), so a restart or a lost event loses nothing. The runner lets workflow runs of one dot run side by side, makes their worktree in the project's repo from the right branch, and commits what they leave with hooks off. Spend is summed from the runs (new input plus output; cache reads apart) and a clock that stops while the person is waited on. `start_workflow` is served like the memory tools: built into the local engine and on Dots' own MCP server, under the one policy name `Workflow`.
**Tech Stack:** Rust (sqlx SQLite, tokio, axum for Dots' MCP server), Tauri 2 app crate (contract samples only), React/zod UI types only. No new dependency.
**Spec:** docs/superpowers/specs/2026-10-23-teams-workflows-design.md (sections 3 to 9 and 13 for the parts listed under "Scope"; Plans B and C do the rest)

## Context

The runner (`runner.rs`) starts queued runs FIFO under `max_concurrent_runs`, one running run per dot, makes a worktree from the dot's `workdir` (`workspace.rs`), builds the prompt (`prompt.rs`) and records engine events. Services that wait on runs are loops that read the store each pass and are woken by `RuntimeEvent::RunUpdated` (the scheduler, the follow-ups). Dots' own tools (check-ins, memory) are performed by `CheckIns` for both engines, built into the local engine and served by Dots' own MCP server, each checked by the approval hub under a policy name that every preset allows (memory spec, migration 0012's `finish_0012`).

    Step {

        name: format!("Step {id}"),
        kind: StepKind::Agent {

            job: "Do it.".into(),

    }

    Step {
        id: id.into(),
        name: "Your check".into(),
        kind: StepKind::Check {},

    Definition {
        trigger: Trigger::Manual,

    vec!["helper".into(), "dev".into()]

//! Workflows (teams and workflows spec section 5): a team's ordered list of steps, with a
//! trigger and a budget. This module holds the definition as the builder saves it and its
//! validation (section 5.8). Steps name members by dot id, so renaming a dot changes nothing.

use std::collections::HashSet;

use serde::{Deserialize, Serialize};

use crate::{Error, Result};

/// The most steps a workflow may have.
pub const MAX_STEPS: usize = 50;
/// The longest step name, in characters after trimming.
pub const MAX_NAME: usize = 80;
/// The longest job of an agent step, in characters after trimming.
pub const MAX_JOB: usize = 8_000;

/// What starts a workflow run (section 5.1).
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum Trigger {
    /// "Run now" or "Test run": the person types the task and picks the project.
    Manual,
    /// A member starts it with `start_workflow` while chatting with the person. `starters` are
    /// the members (dot ids) that may.
    Chat { starters: Vec<String> },
}

/// One entry of the list (sections 5.2 and 5.4).
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Step {
    /// Stable, made by the builder: 1 to 40 of `a-z`, `0-9`, `-` and `_`.
    pub id: String,
    pub name: String,
    #[serde(flatten)]
    pub kind: StepKind,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum StepKind {
    /// A member (a dot id) does one job, added to its own instructions.
    Agent { member: String, job: String },
    /// The workflow waits for the person to approve.
    Check {},
}

/// The limits of one workflow run (section 5.7).
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(default)]
pub struct Budget {
    pub max_runs: u32,
    pub max_tokens: u64,
    pub max_minutes: u32,
    pub max_send_backs: u32,
}

impl Default for Budget {
    fn default() -> Self {
        Budget {
            max_runs: 10,
            max_tokens: 1_500_000,
            max_minutes: 120,
            max_send_backs: 3,
        }
    }
}

/// A workflow as the builder saves it.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Definition {
    pub trigger: Trigger,
    pub steps: Vec<Step>,
    #[serde(default)]
    pub budget: Budget,
}

fn invalid<T>(message: String) -> Result<T> {
    Err(Error::Invalid(message))
}

fn id_ok(id: &str) -> bool {
    (1..=40).contains(&id.len())
        && id
            .bytes()
            .all(|b| b.is_ascii_lowercase() || b.is_ascii_digit() || b == b'-' || b == b'_')
}

impl Definition {
    /// Checks the definition against the team's `members` (dot ids): section 5.8's rules that
    /// apply to the kinds above. The message names the step it is about.
    pub fn validate(&self, members: &[String]) -> Result<()> {
        let member = |id: &str| members.iter().any(|m| m == id);
        if let Trigger::Chat { starters } = &self.trigger {
            if starters.is_empty() {
                return invalid("a chat trigger needs at least one member who starts it".into());
            }
            if let Some(s) = starters.iter().find(|s| !member(s)) {
                return invalid(format!(
                    "the trigger names {s}, who is not a member of the team"
                ));
            }
        }
        if self.steps.is_empty() {
            return invalid("a workflow needs at least one step".into());
        }
        if self.steps.len() > MAX_STEPS {
            return invalid(format!("a workflow has at most {MAX_STEPS} steps"));
        }
        let mut ids = HashSet::new();
        for step in &self.steps {
            let name = step.name.trim();
            if name.is_empty() || name.chars().count() > MAX_NAME {
                return invalid(format!(
                    "step {:?}: a name must be 1 to {MAX_NAME} characters",
                    step.id
                ));
            }
            if !id_ok(&step.id) {
                return invalid(format!(
                    "step \"{name}\": its id must be 1 to 40 of a-z, 0-9, '-' and '_'"
                ));
            }
            if !ids.insert(step.id.as_str()) {
                return invalid(format!(
                    "step \"{name}\": another step has the id {:?}",
                    step.id
                ));
            }
            if let StepKind::Agent { member: m, job } = &step.kind {
                if !member(m) {
                    return invalid(format!("step \"{name}\": {m} is not a member of the team"));
                }
                let job = job.trim();
                if job.is_empty() || job.chars().count() > MAX_JOB {
                    return invalid(format!(
                        "step \"{name}\": the job must be 1 to 8,000 characters"
                    ));
                }
            }
        }
        let b = &self.budget;
        if b.max_runs == 0 || b.max_tokens == 0 || b.max_minutes == 0 || b.max_send_backs == 0 {
            return invalid("every budget limit must be at least 1".into());
        }
        Ok(())
    }

    /// The step with `id` and its place in the list.
    pub fn step(&self, id: &str) -> Option<(usize, &Step)> {
        self.steps.iter().enumerate().find(|(_, s)| s.id == id)
    }

    /// Whether the member `dot_id` may start this workflow from a chat.
    pub fn started_from_chat_by(&self, dot_id: &str) -> bool {
        matches!(&self.trigger, Trigger::Chat { starters } if starters.iter().any(|s| s == dot_id))
    }
}

/// A unique name taken: `Conflict` with `taken`; a member that is not a dot: `Invalid`; any
/// other error as it is.
fn unique(e: sqlx::Error, taken: String) -> Error {
    if let sqlx::Error::Database(db) = &e {
        if db.is_unique_violation() {
            return Error::Conflict(taken);
        }
        if db.is_foreign_key_violation() {
            return Error::Invalid("a member is not a dot".into());
        }
    }
    e.into()
}

fn project_from_row(row: &SqliteRow) -> Result<Project> {
    Ok(Project {
        id: row.try_get("id")?,
        team_id: row.try_get("team_id")?,
        created_at: row.try_get("created_at")?,
        updated_at: row.try_get("updated_at")?,
        spec: ProjectSpec {
            name: row.try_get("name")?,
            repo_path: row.try_get("repo_path")?,
            default_branch: row.try_get("default_branch")?,
            remote: row.try_get("remote")?,
        },
    })
}

/// The workflow of `row`, with `problem` set against the team's `members`.
fn workflow_from_row(row: &SqliteRow, members: &[String]) -> Result<Workflow> {
    let spec = WorkflowSpec {
        name: row.try_get("name")?,
        definition: serde_json::from_str(&row.try_get::<String, _>("definition")?)?,
        enabled: row.try_get::<i64, _>("enabled")? != 0,
    };
    let problem = match spec.definition.validate(members) {
        Err(Error::Invalid(m)) => Some(m),
        Err(e) => Some(e.to_string()),
        Ok(()) => None,
    };
    Ok(Workflow {
        id: row.try_get("id")?,
        team_id: row.try_get("team_id")?,
        created_at: row.try_get("created_at")?,
        updated_at: row.try_get("updated_at")?,
        problem,
        spec,
    })
}

async fn insert_members(
    conn: &mut sqlx::SqliteConnection,
    team_id: &str,
    members: &[MemberSpec],
) -> Result<()> {
    for (i, m) in members.iter().enumerate() {
        sqlx::query(
            "INSERT INTO team_members (team_id, dot_id, role, position) VALUES (?, ?, ?, ?)",
        )
        .bind(team_id)
        .bind(&m.dot_id)
        .bind(m.role.trim())
        .bind(i as i64)
        .execute(&mut *conn)
        .await
        .map_err(|e| unique(e, format!("{} is in the team twice", m.dot_id)))?;
    }
    Ok(())
}

    pub async fn get_workflow_run(&self, id: &str) -> Result<WorkflowRun> {

            "SELECT {WR_COLUMNS} FROM workflow_runs WHERE id = ?"
        ))
        .bind(id)
        .fetch_optional(&self.pool)
        .await?
        .ok_or_else(|| Error::NotFound(format!("workflow run {id}")))?;

            "SELECT {STEP_COLUMNS} FROM workflow_step_runs WHERE workflow_run_id = ? \
             ORDER BY started_at, id"

    pub async fn workflow_run_clock(&self, id: &str) -> Result<Option<String>> {
        Ok(
            sqlx::query_scalar("SELECT clock_at FROM workflow_runs WHERE id = ?")
                .bind(id)
                .fetch_optional(&self.pool)
                .await?
                .flatten(),
        )
    }

    /// Writes `change` to the workflow run, only while it has not ended (`Conflict` after).
    pub async fn set_workflow_run(
        &self,
        id: &str,
        change: &WorkflowRunChange,
    ) -> Result<WorkflowRun> {
        let mut sets: Vec<String> = Vec::new();
        let mut binds: Vec<Option<String>> = Vec::new();
        let mut set = |column: &str, value: Option<String>| {
            sets.push(format!("{column} = ?"));
            binds.push(value);
        };
        if let Some(status) = change.status {
            set("status", Some(status.as_str().into()));
            if status.is_terminal() {
                set("ended_at", Some(now()));
            }
        }
        if let Some(w) = &change.waiting_on {
            set("waiting_on", w.map(|w| w.as_str().into()));
        }
        if let Some(s) = &change.current_step {
            set("current_step", s.clone());
        }
        if let Some(b) = &change.budget {
            set("budget", Some(serde_json::to_string(b)?));
        }
        if let Some(n) = change.send_backs {
            set("send_backs", Some(n.to_string()));
        }
        if let Some(ms) = change.active_ms {
            set("active_ms", Some(ms.to_string()));
        }
        if let Some(c) = &change.clock_at {
            set("clock_at", c.clone());
        }
        if let Some(e) = &change.error {
            set("error", e.clone());
        }
        if !sets.is_empty() {
            let sql = format!(
                "UPDATE workflow_runs SET {} WHERE id = ? AND status IN ('running', 'waiting')",
                sets.join(", ")
            );
            let mut q = sqlx::query(&sql);
            for b in &binds {
                q = q.bind(b);
            }
            let res = q.bind(id).execute(&self.pool).await?;
            if res.rows_affected() == 0 {
                let run = self.get_workflow_run(id).await?;
                return Err(Error::Conflict(format!(
                    "workflow run {id} is already {}",
                    run.status.as_str()
                )));
            }
        }
        self.get_workflow_run(id).await
    }

    pub async fn create_step_run(
        &self,
        workflow_run_id: &str,
        step_id: &str,
        attempt: u32,
        status: StepRunStatus,
    ) -> Result<StepRun> {
        let id = new_id();
        sqlx::query(
            "INSERT INTO workflow_step_runs (id, workflow_run_id, step_id, attempt, status, \
             started_at) VALUES (?, ?, ?, ?, ?, ?)",
        )
        .bind(&id)
        .bind(workflow_run_id)
        .bind(step_id)
        .bind(attempt as i64)
        .bind(status.as_str())
        .bind(now())
        .execute(&self.pool)
        .await?;
        self.get_step_run(&id).await
    }

    pub async fn get_step_run(&self, id: &str) -> Result<StepRun> {
        let row = sqlx::query(&format!(
            "SELECT {STEP_COLUMNS} FROM workflow_step_runs WHERE id = ?"
        ))
        .bind(id)
        .fetch_optional(&self.pool)
        .await?
        .ok_or_else(|| Error::NotFound(format!("step run {id}")))?;
        step_from_row(&row)
    }

    /// Writes `change` to the step run. A terminal status also sets `ended_at`.
    pub async fn set_step_run(&self, id: &str, change: &StepRunChange) -> Result<StepRun> {
        let mut tx = self.pool.begin().await?;
        if let Some(status) = change.status {
            sqlx::query(
                "UPDATE workflow_step_runs SET status = ?, \
                 ended_at = CASE WHEN ? THEN ? ELSE ended_at END WHERE id = ?",
            )
            .bind(status.as_str())
            .bind(status.is_terminal())
            .bind(now())
            .bind(id)
            .execute(&mut *tx)
            .await?;
        }
        if let Some(h) = &change.handoff {
            let text = h.as_ref().map(serde_json::to_string).transpose()?;
            sqlx::query("UPDATE workflow_step_runs SET handoff = ? WHERE id = ?")
                .bind(text)
                .bind(id)
                .execute(&mut *tx)
                .await?;
        }
        if let Some(d) = &change.decision {
            let text = d.as_ref().map(Value::to_string);
            sqlx::query("UPDATE workflow_step_runs SET decision = ? WHERE id = ?")
                .bind(text)
                .bind(id)
                .execute(&mut *tx)
                .await?;
        }
        if let Some(e) = &change.error {
            sqlx::query("UPDATE workflow_step_runs SET error = ? WHERE id = ?")
                .bind(e)
                .bind(id)
                .execute(&mut *tx)
                .await?;
        }
        tx.commit().await?;
        self.get_step_run(id).await
    }

    /// The dot runs of a step run, resume children included, oldest first.
    pub async fn runs_of_step_run(&self, step_run_id: &str) -> Result<Vec<Run>> {
        let ids: Vec<String> = sqlx::query_scalar(
            "SELECT id FROM runs WHERE workflow_step_run_id = ? ORDER BY queued_at, id",
        )
        .bind(step_run_id)
        .fetch_all(&self.pool)
        .await?;
        let mut out = Vec::new();
        for id in ids {
            out.push(self.get_run(&id).await?);
        }
        Ok(out)
    }
}

### Task 5: A workflow step works in its project's repo, and Dots commits what it leaves

For a run with `workflow_step_run_id` the runner reads its workflow run: the worktree (made, restored and cleaned up) is the project's repo's, not the dot's folder, and its branch starts at the payload's `workflow.start`, else the project's default branch, else the repo's (`WorkspaceManager::prepare_from`; a start that is not a commit fails the run). A first prompt of trigger `workflow` carries the payload's `workflow.section` in place of the trigger block.

/// Writes `file` into its workspace (when given), keeps each prompt, and finishes.
struct Writer {
    file: Option<(&'static str, &'static str)>,
    prompts: std::sync::Mutex<Vec<String>>,
}

#[async_trait::async_trait]
impl Engine for Writer {
    async fn start(&self, ctx: RunContext) -> dots_core::Result<mpsc::Receiver<EngineEvent>> {
        self.prompts.lock().unwrap().push(ctx.prompt.clone());
        if let Some((name, text)) = self.file {
            std::fs::write(ctx.workspace.join(name), text).unwrap();
        }
        let (tx, rx) = mpsc::channel(4);
        tx.send(EngineEvent::Finished {
            summary: "Fixed the tray icon.\nMore detail.".into(),
        })
        .await
        .unwrap();
        Ok(rx)
    }
}

fn writer(file: Option<(&'static str, &'static str)>) -> Arc<Writer> {
    Arc::new(Writer {
        file,
        prompts: std::sync::Mutex::new(Vec::new()),
    })
}

/// A dot in worktree mode whose own folder is a repo of its own, not the project's.
async fn worktree_dot(store: &Store, dir: &TempDir, name: &str) -> Dot {
    let own = dir.path().join(format!("{name}-own"));
    init_repo(&own);
    let mut s = spec(name);
    s.workdir = own.to_string_lossy().to_string();
    s.workspace_mode = WorkspaceMode::Worktree;
    store.create_dot(&s).await.unwrap()
}

async fn queue_with(runner: &Runner, dot: &Dot, step: &str, payload: serde_json::Value) -> Run {

    new.workflow_step_run_id = Some(step.to_string());

}

### Task 6: Workflow runs move through agent steps and checks

`workflows::Workflows` starts a workflow run (refusing a blank task, a workflow turned off or with a problem, a project of another team or no longer a repo) and moves every run in flight in passes: the first step; an agent step queues its member's run with the `## Workflow` section (role, team, workflow, project, step, task, job, earlier hand-offs) and the start branch; it ends when no question of its runs is open and its runs' thread has ended (the question is read first: an answer and the run it starts are one transaction); a succeeded step hands on the newest run's summary and its branch when the branch still exists; a check waits; a failed step (run failed or cancelled, member disabled or gone) waits for `retry_step` or `stop`. `approve_check` passes on the hand-off the check was shown. `stop` cancels the runs and closes the steps. `Workflows::delete_team` stops the team's runs in flight and deletes it; `Teams::delete` refuses while any are. #[derive(Clone)]
enum Act {
    /// Finishes with this summary.
    Finish(&'static str),
    /// Writes a file into its workspace, then finishes with this summary.
    Write(&'static str, &'static str),
    /// Fails with this error.
    Fail(&'static str),
    /// Asks the person this question, then finishes.
    Ask(&'static str),
    /// Runs until it is cancelled.
    Hold,
}

/// Plays each dot's acts in order, one per run (the last one again once they run out), and
/// keeps each run's prompt.
struct Team {
    store: Store,
    acts: Mutex<HashMap<String, VecDeque<Act>>>,
    prompts: Mutex<Vec<(String, String)>>,
}

impl Team {
    fn act(&self, dot: &str) -> Act {
        let mut acts = self.acts.lock().unwrap();
        let queue = acts.entry(dot.to_string()).or_default();
        match queue.len() {
            0 => Act::Finish("done"),
            1 => queue[0].clone(),
            _ => queue.pop_front().unwrap(),
        }
    }

    fn set(&self, dot: &str, acts: Vec<Act>) {
        self.acts
            .lock()
            .unwrap()
            .insert(dot.to_string(), acts.into());
    }

    fn prompts_of(&self, dot: &str) -> Vec<String> {
        self.prompts
            .lock()
            .unwrap()
            .iter()
            .filter(|(d, _)| d == dot)
            .map(|(_, p)| p.clone())
            .collect()
    }
}

#[async_trait::async_trait]
impl Engine for Team {
    async fn start(&self, ctx: RunContext) -> dots_core::Result<mpsc::Receiver<EngineEvent>> {
        let name = ctx.dot.spec.name.clone();
        self.prompts
            .lock()
            .unwrap()
            .push((name.clone(), ctx.prompt.clone()));
        let act = self.act(&name);
        let store = self.store.clone();
        let (tx, rx) = mpsc::channel(8);
        tokio::spawn(async move {
            let session = format!("session-{}", ctx.run_id);
            let _ = tx
                .send(EngineEvent::SessionStarted {
                    session_id: session,
                })
                .await;
            let end = match act {
                Act::Finish(s) => EngineEvent::Finished { summary: s.into() },
                Act::Write(file, s) => {
                    std::fs::write(ctx.workspace.join(file), s).unwrap();
                    EngineEvent::Finished { summary: s.into() }
                }
                Act::Fail(e) => EngineEvent::Failed { error: e.into() },
                Act::Ask(q) => {
                    store
                        .add_question(&ctx.dot.id, &ctx.run_id, q, None)
                        .await
                        .unwrap();
                    EngineEvent::Finished {
                        summary: "I asked.".into(),
                    }
                }
                Act::Hold => {
                    ctx.cancel.cancelled().await;
                    return;
                }
            };
            let _ = tx.send(end).await;
        });
        Ok(rx)
    }

    /// Waits until the workflow run satisfies `done`, or panics with its last state.
    async fn until(&self, id: &str, done: impl Fn(&WorkflowRun) -> bool) -> WorkflowRun {
        // Generous: under a full test run, git on Windows makes each step take seconds.
        let deadline = std::time::Instant::now() + Duration::from_secs(60);
        loop {
            let wr = self.store.get_workflow_run(id).await.unwrap();
            if done(&wr) {
                return wr;
            }
            if std::time::Instant::now() > deadline {
                let mut runs = Vec::new();
                for s in &wr.steps {
                    for r in self.store.runs_of_step_run(&s.id).await.unwrap() {
                        runs.push((s.step_id.clone(), r.status, r.error, r.ended_at));
                    }
                }
                panic!("workflow run {id} did not get there; runs {runs:?}; last state: {wr:#?}");
            }
            tokio::time::sleep(Duration::from_millis(30)).await;
        }
    }
}

fn waits_on(w: WaitingOn) -> impl Fn(&WorkflowRun) -> bool {
    move |wr| wr.status == WorkflowRunStatus::Waiting && wr.waiting_on == Some(w)
}

//! Workflow runs (teams and workflows spec sections 5 to 8). `Workflows` starts them and moves
//! each one along its steps: an agent step queues a run of its member and ends when that run's
//! thread does; a check waits for the person. Every move is made by a pass that reads the
//! workflow runs in flight from the store and does what each one's state calls for, so a
//! restart or a lost event never loses a step. The loop passes when a run of a step changes,
//! when a question is posted or answered, when it is woken, and every `TICK`.

use std::path::Path;
use std::sync::Arc;
use std::time::Duration;

use serde_json::json;
use tokio::sync::broadcast::error::RecvError;
use tokio::sync::broadcast::Receiver;
use tokio::sync::{Mutex, Notify};
use tokio::task::JoinHandle;
use tokio_util::sync::CancellationToken;

use crate::events::{Bus, RuntimeEvent};
use crate::model::{
    BranchRef, Handoff, NewRun, NewWorkflowRun, Run, RunStatus, StepRun, StepRunChange,
    StepRunStatus, TriggerKind, WaitingOn, WorkflowRun, WorkflowRunChange, WorkflowRunStatus,
    WorkflowTrigger,
};
use crate::runner::Runner;
use crate::scheduler::Clock;
use crate::store::Store;
use crate::workflow::{Step, StepKind};
use crate::workspace::git;
use crate::{Error, Result};

/// The longest task, in characters after trimming.
pub const MAX_TASK: usize = 8_000;
/// The longest summary of an earlier step a prompt carries, in characters.
pub const MAX_HANDOFF_SUMMARY: usize = 4_000;
/// How often the loop passes while nothing wakes it.
pub const TICK: Duration = Duration::from_secs(30);

/// What starts a workflow run.
#[derive(Debug, Clone, PartialEq)]
pub struct StartRequest {
    pub workflow_id: String,
    pub project_id: String,
    pub task: String,
    pub trigger: WorkflowTrigger,
    /// The chat run that started it (`start_workflow`).
    pub origin_run_id: Option<String>,
    /// A test run: its deploy steps push nothing (section 5.1).
    pub test: bool,
}

pub struct Workflows {
    store: Store,
    bus: Bus,
    runner: Arc<Runner>,
    clock: Arc<dyn Clock>,
    wake: Notify,
    /// Held by each pass and each of the person's actions, so no two move one run at once.
    lock: Mutex<()>,
}

/// The newest step run of `step_id`.
fn latest<'a>(wr: &'a WorkflowRun, step_id: &str) -> Option<&'a StepRun> {
    wr.steps.iter().rev().find(|s| s.step_id == step_id)
}

/// The hand-offs of the agent steps before `index`, oldest first: each step's newest
/// succeeded run.
fn handoffs_before(wr: &WorkflowRun, index: usize) -> Vec<(&Step, &Handoff)> {
    wr.definition.steps[..index]
        .iter()
        .filter(|s| matches!(s.kind, StepKind::Agent { .. }))
        .filter_map(|s| {
            let run = wr
                .steps
                .iter()
                .rev()
                .find(|r| r.step_id == s.id && r.status == StepRunStatus::Succeeded)?;
            Some((s, run.handoff.as_ref()?))
        })
        .collect()
}

/// The branch a step at `index` starts from (section 6): the newest earlier hand-off that has
/// branches, when it has exactly one. `None` starts from the project's default branch.
fn start_branch(wr: &WorkflowRun, index: usize) -> Option<String> {
    let newest = handoffs_before(wr, index)
        .into_iter()
        .rev()
        .find(|(_, h)| !h.branches.is_empty())?;
    match newest.1.branches.as_slice() {
        [only] => Some(only.branch.clone()),
        _ => None,
    }
}

fn cut(text: &str, max: usize) -> String {
    if text.chars().count() <= max {
        return text.to_string();
    }
    let mut out: String = text.chars().take(max).collect();
    out.push_str(" [cut]");
    out
}

impl Workflows {
    pub fn new(store: Store, bus: Bus, runner: Arc<Runner>, clock: Arc<dyn Clock>) -> Arc<Self> {
        Arc::new(Self {
            store,
            bus,
            runner,
            clock,
            wake: Notify::new(),
            lock: Mutex::new(()),
        })
    }

    fn updated(&self, wr: &WorkflowRun) {
        let _ = self
            .bus
            .send(RuntimeEvent::WorkflowRunUpdated { run: wr.clone() });
    }

    /// Makes the loop pass now.
    pub fn wake(&self) {
        self.wake.notify_one();
    }

    pub async fn get(&self, id: &str) -> Result<WorkflowRun> {
        self.store.get_workflow_run(id).await
    }

    /// The newest workflow runs, of one team or of all.
    pub async fn list(&self, team_id: Option<&str>, limit: i64) -> Result<Vec<WorkflowRun>> {
        self.store.list_workflow_runs(team_id, limit).await
    }

    /// Starts a run of a workflow on one of its team's projects. Refused for a workflow that is
    /// turned off or has a `problem`, a project of another team or whose folder is no longer a
    /// git repo, and a task that is blank or longer than `MAX_TASK`.
    pub async fn start(&self, req: StartRequest) -> Result<WorkflowRun> {
        let task = req.task.trim();
        if task.is_empty() || task.chars().count() > MAX_TASK {
            return Err(Error::Invalid(
                "the task must be 1 to 8,000 characters".into(),
            ));
        }
        let workflow = self.store.get_workflow(&req.workflow_id).await?;
        let name = &workflow.spec.name;
        if !workflow.spec.enabled {
            return Err(Error::Conflict(format!("workflow {name} is turned off")));
        }
        if let Some(problem) = &workflow.problem {
            return Err(Error::Invalid(format!(
                "workflow {name} cannot start: {problem}"
            )));
        }
        let project = self.store.get_project(&req.project_id).await?;
        if project.team_id != workflow.team_id {
            return Err(Error::Invalid(format!(
                "{} is not a project of the workflow's team",
                project.spec.name
            )));
        }
        crate::teams::check_repo(&project.spec.repo_path).await?;
        let wr = self
            .store
            .create_workflow_run(&NewWorkflowRun {
                workflow_id: workflow.id.clone(),
                team_id: workflow.team_id.clone(),
                definition: workflow.spec.definition.clone(),
                project_id: project.id.clone(),
                project: project.spec.clone(),
                task: task.to_string(),
                trigger: req.trigger,
                origin_run_id: req.origin_run_id,
                test: req.test,
            })
            .await?;
        self.updated(&wr);
        self.wake();
        Ok(wr)
    }

    /// Approves the check the workflow run waits on (section 5.4): the check passes the hand-off
    /// it was shown on, and the workflow goes on.
    pub async fn approve_check(&self, id: &str, note: Option<&str>) -> Result<WorkflowRun> {
        let _one = self.lock.lock().await;
        let wr = self.store.get_workflow_run(id).await?;
        let step_run = match (&wr.status, &wr.waiting_on, &wr.current_step) {
            (WorkflowRunStatus::Waiting, Some(WaitingOn::Check), Some(current)) => {
                latest(&wr, current).cloned()
            }
            _ => None,
        };
        let Some(step_run) = step_run else {
            return Err(Error::Conflict(format!(
                "workflow run {id} is not waiting for a check"
            )));
        };
        let index = wr.definition.step(&step_run.step_id).map_or(0, |(i, _)| i);
        let shown = handoffs_before(&wr, index)
            .last()
            .map(|(_, h)| (*h).clone())
            .unwrap_or_default();
        let note = note.map(str::trim).filter(|n| !n.is_empty());
        self.store
            .set_step_run(
                &step_run.id,
                &StepRunChange {
                    status: Some(StepRunStatus::Succeeded),
                    handoff: Some(Some(shown)),
                    decision: Some(Some(json!({"decision": "approved", "note": note}))),
                    ..Default::default()
                },
            )
            .await?;
        self.store
            .set_workflow_run(
                id,
                &WorkflowRunChange {
                    status: Some(WorkflowRunStatus::Running),
                    waiting_on: Some(None),
                    ..Default::default()
                },
            )
            .await?;
        self.advance(id).await?;
        let wr = self.store.get_workflow_run(id).await?;
        self.updated(&wr);
        Ok(wr)
    }

    /// Runs the failed step again, as a new attempt (sections 8 and 10.3).
    pub async fn retry_step(&self, id: &str) -> Result<WorkflowRun> {
        let _one = self.lock.lock().await;
        let wr = self.store.get_workflow_run(id).await?;
        let index = match (&wr.status, &wr.waiting_on, &wr.current_step) {
            (WorkflowRunStatus::Waiting, Some(WaitingOn::StepFailed), Some(current)) => {
                wr.definition.step(current).map(|(i, _)| i)
            }
            _ => None,
        };
        let Some(index) = index else {
            return Err(Error::Conflict(format!(
                "workflow run {id} has no failed step to retry"
            )));
        };
        let wr = self
            .store
            .set_workflow_run(
                id,
                &WorkflowRunChange {
                    status: Some(WorkflowRunStatus::Running),
                    waiting_on: Some(None),
                    error: Some(None),
                    ..Default::default()
                },
            )
            .await?;
        self.begin_step(&wr, index).await?;
        let wr = self.store.get_workflow_run(id).await?;
        self.updated(&wr);
        Ok(wr)
    }

    /// Stops the workflow run (section 8): its queued and running dot runs are cancelled, its
    /// open steps and a waiting check are closed as cancelled.
    pub async fn stop(&self, id: &str) -> Result<WorkflowRun> {
        let _one = self.lock.lock().await;
        self.stop_locked(id).await
    }

    async fn stop_locked(&self, id: &str) -> Result<WorkflowRun> {
        let wr = self.store.get_workflow_run(id).await?;
        if wr.status.is_terminal() {
            return Err(Error::Conflict(format!(
                "workflow run {id} is already {}",
                wr.status.as_str()
            )));
        }
        for step_run in wr.steps.iter().filter(|s| !s.status.is_terminal()) {
            for run in self.store.runs_of_step_run(&step_run.id).await? {
                if !run.status.is_terminal() {
                    if let Err(e) = self.runner.cancel(&run.id).await {
                        tracing::warn!(run = %run.id, "cancelling a workflow's run failed: {e}");
                    }
                }
            }
            self.store
                .set_step_run(
                    &step_run.id,
                    &StepRunChange {
                        status: Some(StepRunStatus::Cancelled),
                        ..Default::default()
                    },
                )
                .await?;
        }
        let wr = self
            .store
            .set_workflow_run(
                id,
                &WorkflowRunChange {
                    status: Some(WorkflowRunStatus::Cancelled),
                    waiting_on: Some(None),
                    ..Default::default()
                },
            )
            .await?;
        self.updated(&wr);
        Ok(wr)
    }

    /// Stops the team's workflow runs in flight, then deletes the team (section 4).
    pub async fn delete_team(&self, team_id: &str) -> Result<()> {
        let _one = self.lock.lock().await;
        for wr in self
            .store
            .list_workflow_runs(Some(team_id), i64::MAX)
            .await?
        {
            if !wr.status.is_terminal() {
                self.stop_locked(&wr.id).await?;
            }
        }
        self.store.delete_team(team_id).await?;
        let _ = self.bus.send(RuntimeEvent::TeamUpdated {
            team_id: team_id.to_string(),
        });
        Ok(())
    }

    /// Runs the loop until `shutdown`.
    pub fn spawn(self: &Arc<Self>, shutdown: CancellationToken) -> JoinHandle<()> {
        let this = self.clone();
        // Subscribed before the first pass, so no change it should see is missed.
        let mut events = self.bus.subscribe();
        tokio::spawn(async move {
            loop {
                if let Err(e) = this.pass().await {
                    tracing::error!("workflow pass failed: {e}");
                }
                tokio::select! {
                    biased;
                    _ = shutdown.cancelled() => break,
                    _ = this.wake.notified() => {}
                    _ = relevant(&mut events) => {}
                    _ = tokio::time::sleep(TICK) => {}
                }
            }
        })
    }

    /// One pass over the workflow runs in flight. A run whose move fails is logged and tried
    /// again on the next pass.
    pub async fn pass(&self) -> Result<()> {
        let _one = self.lock.lock().await;
        for id in self.store.workflow_runs_in_flight().await? {
            if let Err(e) = self.advance(&id).await {
                tracing::warn!(workflow_run = %id, "moving the workflow run failed: {e}");
            }
        }
        Ok(())
    }

    /// Does what the workflow run's state calls for: start its first step, watch the step that
    /// runs, or start the step after one that succeeded. A waiting run waits for the person.
    async fn advance(&self, id: &str) -> Result<()> {
        let wr = self.store.get_workflow_run(id).await?;
        if wr.status != WorkflowRunStatus::Running {
            return Ok(());
        }
        let Some(current) = wr.current_step.clone() else {
            return self.begin_step(&wr, 0).await;
        };
        let Some((index, _)) = wr.definition.step(&current) else {
            return Err(Error::Other(format!(
                "step {current} is not in the workflow"
            )));
        };
        match latest(&wr, &current).map(|s| (s.status, s.clone())) {
            None => self.begin_step(&wr, index).await,
            Some((StepRunStatus::Running, step_run)) => {
                self.watch_agent(&wr, index, &step_run).await
            }
            Some((StepRunStatus::Succeeded, _)) => self.begin_step(&wr, index + 1).await,
            Some(_) => Ok(()),
        }
    }

    /// Starts the step at `index`: an agent step queues its member's run, a check waits for the
    /// person. Past the last step the workflow run has succeeded.
    async fn begin_step(&self, wr: &WorkflowRun, index: usize) -> Result<()> {
        let Some(step) = wr.definition.steps.get(index) else {
            let done = self
                .store
                .set_workflow_run(
                    &wr.id,
                    &WorkflowRunChange {
                        status: Some(WorkflowRunStatus::Succeeded),
                        current_step: Some(None),
                        ..Default::default()
                    },
                )
                .await?;
            self.updated(&done);
            return Ok(());
        };
        let attempt = wr.steps.iter().filter(|s| s.step_id == step.id).count() as u32 + 1;
        match &step.kind {
            StepKind::Check {} => {
                self.store
                    .create_step_run(&wr.id, &step.id, attempt, StepRunStatus::Waiting)
                    .await?;
                let waiting = self
                    .store
                    .set_workflow_run(
                        &wr.id,
                        &WorkflowRunChange {
                            status: Some(WorkflowRunStatus::Waiting),
                            waiting_on: Some(Some(WaitingOn::Check)),
                            current_step: Some(Some(step.id.clone())),
                            ..Default::default()
                        },
                    )
                    .await?;
                self.updated(&waiting);
            }
            StepKind::Agent { member, .. } => {
                let refusal = match self.store.get_dot(member).await {
                    Ok(dot) if dot.spec.enabled => None,
                    Ok(dot) => Some(format!("{} is disabled", dot.spec.name)),
                    Err(Error::NotFound(_)) => Some("its member is no longer a dot".to_string()),
                    Err(e) => return Err(e),
                };
                let status = if refusal.is_some() {
                    StepRunStatus::Failed
                } else {
                    StepRunStatus::Running
                };
                let step_run = self
                    .store
                    .create_step_run(&wr.id, &step.id, attempt, status)
                    .await?;
                self.store
                    .set_workflow_run(
                        &wr.id,
                        &WorkflowRunChange {
                            current_step: Some(Some(step.id.clone())),
                            ..Default::default()
                        },
                    )
                    .await?;
                match refusal {
                    Some(error) => self.fail_step(wr, step, &step_run, &error).await?,
                    None => {
                        let wr = self.store.get_workflow_run(&wr.id).await?;
                        self.queue_agent_run(&wr, index, &step_run).await?;
                        self.updated(&self.store.get_workflow_run(&wr.id).await?);
                    }
                }
            }
        }
        Ok(())
    }

    /// Queues the run of an agent step's member, with the `## Workflow` section and the branch
    /// it starts from in its payload (sections 5.2 and 6).
    async fn queue_agent_run(
        &self,
        wr: &WorkflowRun,
        index: usize,
        step_run: &StepRun,
    ) -> Result<Run> {
        let step = &wr.definition.steps[index];
        let StepKind::Agent { member, .. } = &step.kind else {
            return Err(Error::Other(format!(
                "step {} is not an agent step",
                step.id
            )));
        };
        let section = self.section(wr, index).await?;
        let mut new = NewRun::new(member, TriggerKind::Workflow);
        new.workflow_step_run_id = Some(step_run.id.clone());
        new.payload = Some(json!({
            "workflow": {
                "workflow_run_id": wr.id,
                "step_id": step.id,
                "start": start_branch(wr, index),
                "section": section,
            }
        }));
        self.runner.enqueue(new).await
    }

    /// The `## Workflow` section of the prompt of the step at `index` (section 5.2).
    async fn section(&self, wr: &WorkflowRun, index: usize) -> Result<String> {
        let step = &wr.definition.steps[index];
        let StepKind::Agent { member, job } = &step.kind else {
            return Ok(String::new());
        };
        let team = self.store.get_team(&wr.team_id).await?;
        let role = team
            .members
            .iter()
            .find(|m| &m.dot_id == member)
            .map(|m| m.role.trim().to_string())
            .filter(|r| !r.is_empty());
        let workflow = match &wr.workflow_id {
            Some(id) => self.store.get_workflow(id).await.ok().map(|w| w.spec.name),
            None => None,
        }
        .unwrap_or_else(|| "this workflow".to_string());
        let mut out = String::from("## Workflow\n\n");
        out.push_str(&format!(
            "You are {} of the team \"{}\", doing one step of the workflow \"{}\".\n\n",
            role.map_or("a member".to_string(), |r| format!("the {r}")),
            team.name,
            workflow
        ));
        out.push_str(&format!(
            "- Project: {} ({})\n",
            wr.project.name, wr.project.repo_path
        ));
        out.push_str(&format!(
            "- Step: {} ({} of {})\n\n",
            step.name,
            index + 1,
            wr.definition.steps.len()
        ));
        out.push_str("### Task\n\n");
        out.push_str(wr.task.trim());
        out.push_str("\n\n### Your job in this step\n\n");
        out.push_str(job.trim());
        out.push_str("\n\n");
        let earlier = handoffs_before(wr, index);
        if !earlier.is_empty() {
            out.push_str("### Earlier steps\n\n");
            for (s, h) in earlier {
                out.push_str(&format!("#### {}\n\n", s.name));
                let summary = h.summary.trim();
                out.push_str(if summary.is_empty() {
                    "(no summary)"
                } else {
                    summary
                });
                out.push_str("\n\n");
                if !h.branches.is_empty() {
                    let names: Vec<&str> = h.branches.iter().map(|b| b.branch.as_str()).collect();
                    out.push_str(&format!("Branches: {}\n\n", names.join(", ")));
                }
            }
        }
        out.push_str(
            "When you are done, end with a summary of what you did: the next step gets it.\n",
        );
        Ok(out)
    }

    /// Watches an agent step's runs: it ends when its newest run's thread has ended and no
    /// question of it waits for the person. A step whose run is gone gets one again.
    async fn watch_agent(&self, wr: &WorkflowRun, index: usize, step_run: &StepRun) -> Result<()> {
        // The question first: an answer closes it and stores the run that continues the thread
        // in one transaction, so once it reads as closed, the runs read next include that run.
        if self.store.step_has_open_question(&step_run.id).await? {
            return Ok(());
        }
        let runs = self.store.runs_of_step_run(&step_run.id).await?;
        let Some(last) = runs.last() else {
            self.queue_agent_run(wr, index, step_run).await?;
            return Ok(());
        };
        if runs.iter().any(|r| !r.status.is_terminal()) {
            return Ok(());
        }
        let step = &wr.definition.steps[index];
        if last.status != RunStatus::Succeeded {
            let error = last.error.clone().unwrap_or_else(|| match last.status {
                RunStatus::Cancelled => "the run was cancelled".to_string(),
                _ => "the run failed".to_string(),
            });
            return self.fail_step(wr, step, step_run, &error).await;
        }
        let handoff = self.handoff_of(wr, &runs).await;
        self.store
            .set_step_run(
                &step_run.id,
                &StepRunChange {
                    status: Some(StepRunStatus::Succeeded),
                    handoff: Some(Some(handoff)),
                    ..Default::default()
                },
            )
            .await?;
        let wr = self.store.get_workflow_run(&wr.id).await?;
        self.begin_step(&wr, index + 1).await
    }

    /// Fails a step: the workflow run waits for the person to retry it or stop (section 8).
    async fn fail_step(
        &self,
        wr: &WorkflowRun,
        step: &Step,
        step_run: &StepRun,
        error: &str,
    ) -> Result<()> {
        self.store
            .set_step_run(
                &step_run.id,
                &StepRunChange {
                    status: Some(StepRunStatus::Failed),
                    error: Some(Some(error.to_string())),
                    ..Default::default()
                },
            )
            .await?;
        let waiting = self
            .store
            .set_workflow_run(
                &wr.id,
                &WorkflowRunChange {
                    status: Some(WorkflowRunStatus::Waiting),
                    waiting_on: Some(Some(WaitingOn::StepFailed)),
                    error: Some(Some(format!("{}: {error}", step.name))),
                    ..Default::default()
                },
            )
            .await?;
        self.updated(&waiting);
        Ok(())
    }

    /// What a finished agent step hands on (section 6): its newest run's summary, and the
    /// branch of its thread when the branch still exists (a worktree with no change was
    /// removed with its branch).
    async fn handoff_of(&self, wr: &WorkflowRun, runs: &[Run]) -> Handoff {
        let last = runs.last();
        let summary = last.and_then(|r| r.summary.clone()).unwrap_or_default();
        let mut branches = Vec::new();
        if let Some(run) = runs.iter().rev().find(|r| r.branch.is_some()) {
            let branch = run.branch.clone().unwrap_or_default();
            let exists = git(
                Path::new(&wr.project.repo_path),
                &[
                    "rev-parse",
                    "--verify",
                    "--quiet",
                    "--end-of-options",
                    &format!("refs/heads/{branch}"),
                ],
            )
            .await
            .is_ok();
            if exists {
                branches.push(BranchRef {
                    run_id: run.id.clone(),
                    branch,
                    worktree_path: run.workspace_path.clone().unwrap_or_default(),
                    base_commit: run.base_commit.clone(),
                });
            }
        }
        Handoff {
            summary: cut(&summary, MAX_HANDOFF_SUMMARY),
            branches,
            outcome: None,
        }
    }

    /// The time now, from the clock the workflow runs count with.
    pub fn now(&self) -> chrono::DateTime<chrono::Utc> {
        self.clock.now()
    }
}

/// Returns when something a pass should see happened: a run of a workflow step changed, a

    loop {
        match events.recv().await {
            Ok(RuntimeEvent::RunUpdated { run }) if run.workflow_step_run_id.is_some() => return,
            Ok(RuntimeEvent::MessagePosted { .. })
            | Ok(RuntimeEvent::MessageUpdated { .. })
            | Ok(RuntimeEvent::ApprovalRequested { .. })
            | Ok(RuntimeEvent::ApprovalDecided { .. }) => return,
            Ok(_) => {}
            Err(RecvError::Lagged(_)) => return,
            Err(RecvError::Closed) => std::future::pending().await,
        }
    }
}

### Task 7: A workflow run keeps to its budget; its clock stops while it waits on the person

Before an agent step queues a run, `workflows::budget_reached` compares what the workflow run spent with its `budget` (runs, new tokens, active minutes); past a limit the run waits (`budget`, error `Budget reached: …`) and `add_budget` raises each reached limit by its default amount once and lets it go. Each pass, and each of the person's actions, first counts the time since the run's clock last counted into `active_ms`, unless it was waiting or one of its runs waits on the person (`Store::workflow_waits_on_person`: parked, an approval pending, a question open). /// The limit the workflow run has reached, if any (section 9), as the person reads it: a new
/// dot run of it may start only while none is reached.
pub fn budget_reached(wr: &WorkflowRun) -> Option<String> {
    let b = &wr.budget;
    if wr.spent_runs >= b.max_runs {
        return Some(format!("runs, {} of {}", wr.spent_runs, b.max_runs));
    }
    if wr.spent_tokens >= b.max_tokens {
        return Some(format!("tokens, {} of {}", wr.spent_tokens, b.max_tokens));
    }
    let minutes = wr.active_ms / 60_000;
    if wr.active_ms >= u64::from(b.max_minutes) * 60_000 {
        return Some(format!("minutes, {minutes} of {}", b.max_minutes));
    }
    None
}

/// `budget` with each limit `wr` has reached raised by that limit's default amount (section 9,
/// "Add budget").
fn raised(wr: &WorkflowRun) -> Budget {
    let mut b = wr.budget;
    let more = Budget::default();
    if wr.spent_runs >= b.max_runs {
        b.max_runs = b.max_runs.saturating_add(more.max_runs);
    }
    if wr.spent_tokens >= b.max_tokens {
        b.max_tokens = b.max_tokens.saturating_add(more.max_tokens);
    }
    if wr.active_ms >= u64::from(b.max_minutes) * 60_000 {
        b.max_minutes = b.max_minutes.saturating_add(more.max_minutes);
    }
    b
}

/// A runtime whose Claude engine is `fake-claude` playing `script`.
async fn start(script: Value) -> Rt {
    let dir = tempfile::tempdir().unwrap();
    let script_path = dir.path().join("script.json");
    std::fs::write(&script_path, script.to_string()).unwrap();
    let args_out = dir.path().join("args.json");
    let mut cfg = Config::new(dir.path().join("data"));
    cfg.port = 0;
    cfg.claude_path = Some(PathBuf::from(env!("CARGO_BIN_EXE_fake-claude")));
    cfg.claude_env = vec![
        (
            "FAKE_CLAUDE_SCRIPT".into(),
            script_path.to_string_lossy().to_string(),
        ),
        (
            "FAKE_CLAUDE_ARGS_OUT".into(),
            args_out.to_string_lossy().to_string(),
        ),
    ];
    cfg.local_retry_delays = vec![Duration::ZERO; 2];
    let rt = Runtime::start(cfg).await.unwrap();
    Rt { dir, rt, args_out }
}

/// A team with `helper`, a project, and a workflow "Fix" whose chat trigger names the helper
/// and whose one step is the person's check.
async fn team_of(t: &Rt, helper: &Dot) -> String {
    let team =
        t.rt.teams()
            .create(&TeamSpec {
                name: "Dots management".into(),
                description: String::new(),
                members: vec![MemberSpec {
                    dot_id: helper.id.clone(),
                    role: "user helper".into(),
                }],
            })
            .await
            .unwrap();
    let repo = t.dir.path().join("repo");
    init_repo(&repo);
    t.rt.teams()
        .add_project(
            &team.id,
            &ProjectSpec {
                name: "Dots".into(),
                repo_path: repo.to_string_lossy().to_string(),
                default_branch: None,
                remote: "origin".into(),
            },
        )
        .await
        .unwrap();
    t.rt.teams()
        .create_workflow(
            &team.id,
            &WorkflowSpec {
                name: "Fix".into(),
                definition: Definition {
                    trigger: Trigger::Chat {
                        starters: vec![helper.id.clone()],
                    },
                    steps: vec![Step {
                        id: "check".into(),
                        name: "Your check".into(),
                        kind: StepKind::Check {},
                    }],
                    budget: Budget::default(),
                },
                enabled: true,
            },
        )
        .await
        .unwrap();
    team.id
}

fn local_spec(t: &Rt, endpoint: &str, name: &str) -> DotSpec {

    s.engine = EngineKind::Local;

fn tool_names(req: &Value) -> Vec<String> {
    req["tools"]
        .as_array()
        .unwrap()
        .iter()
        .map(|t| t["function"]["name"].as_str().unwrap().to_string())
        .collect()
}

fn prompt(req: &Value) -> String {
    messages(req)
        .iter()
        .find(|m| m["role"] == "user")
        .and_then(|m| m["content"].as_str())
        .unwrap_or_default()
        .to_string()
}

        first.contains(

        ),
        "{first}"
    );
    let answers: Vec<String> = (1..=4)
        .map(|i| tool_result(&reqs[i], &format!("c{i}")))
        .collect();
    assert_eq!(
        answers,
        [
            "There is no workflow named \"Deploy\" that you may start.",
            "The team \"Dots management\" has no project named \"Other\".",
            "Not started: the task must be 1 to 8,000 characters.",
            "Workflow \"Fix\" started on \"Dots\".",
        ]
    );
    let runs = t.rt.workflows().list(None, 10).await.unwrap();
    assert_eq!(runs.len(), 1);
    let wr = &runs[0];
    assert_eq!(wr.trigger, WorkflowTrigger::Chat);
    assert_eq!(wr.origin_run_id.as_deref(), Some(chat.id.as_str()));
    assert_eq!(wr.task, "The tray icon is invisible in dark mode.");
    // Its one step is the check, so it waits for the person.
    let deadline = std::time::Instant::now() + Duration::from_secs(30);
    loop {
        let wr = t.rt.workflows().get(&wr.id).await.unwrap();
        if wr.status == WorkflowRunStatus::Waiting {
            assert_eq!(wr.waiting_on, Some(WaitingOn::Check));
            break;
        }
        assert!(std::time::Instant::now() < deadline, "{wr:#?}");
        tokio::time::sleep(Duration::from_millis(50)).await;

    let plain = t.rt.run_now(&helper.id).await.unwrap();
    wait_status(t.rt.store(), &plain.id, RunStatus::Succeeded, 30).await;
    let last = llm.requests().last().unwrap().clone();
    assert!(!tool_names(&last).contains(&"start_workflow".to_string()));
    assert!(!prompt(&last).contains("## Workflows you can start"));
    t.rt.shutdown();
}

/// Checks a `start_workflow` call against the dot's policy under `Workflow`, waiting for an
/// approval when a rule asks, and starts the workflow (teams spec section 7). A call that is not
/// performed is a tool result with `isError`, as for the check-in tools.
async fn call_workflow(s: &ServerState, run_id: &str, req: &Value) -> Result<Value, (i64, String)> {
    let (Some(checkins), Some(tools)) = (
        s.runner.checkins(),
        s.runner
            .run_tools(run_id)
            .filter(|tools| !tools.startable().is_empty()),
    ) else {
        return Err((-32602, "unknown tool".to_string()));
    };
    let Some(workflows) = checkins.workflows() else {
        return Err((-32602, "unknown tool".to_string()));
    };
    let params = req
        .get("params")
        .ok_or((-32602, "missing params".to_string()))?;
    let mut input = match params.get("arguments") {
        None | Some(Value::Null) => json!({}),
        Some(args @ Value::Object(_)) => args.clone(),
        Some(_) => return Err((-32602, "params.arguments must be an object".to_string())),
    };
    // Only the tool's own arguments, as the local engine's `prepare` keeps.
    let own = TeamTool::StartWorkflow.properties();
    if let (Value::Object(args), Value::Object(own)) = (&mut input, &own) {
        args.retain(|key, _| own.contains_key(key));
    }
    let input = match s.hub.check(run_id, team_tools::POLICY_NAME, input).await {
        Ok(PermissionOutcome::Allow { input }) => input,
        Ok(PermissionOutcome::Deny { message }) => return Ok(not_performed(&message)),
        Err(e) => return Ok(not_performed(&format!("permission check failed: {e}"))),
    };
    Ok(
        match workflows
            .call_start(run_id, tools.startable(), &input)
            .await
        {
            Ok(text) => json!({ "content": [{ "type": "text", "text": text }] }),
            Err(text) => not_performed(&text),
        },
    )
}

        &self,

        let arg = |key: &str| {
            input
                .get(key)
                .and_then(serde_json::Value::as_str)

                .unwrap_or_default()
                .to_string()
        };

            .iter()

                project_id,

                test: false,
            })

                "Workflow \"{}\" started on \"{project}\".",
                workflow.workflow

            Err(e) => {
