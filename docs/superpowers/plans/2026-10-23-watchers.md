# Watchers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A dot starts on its own when a file changes in a folder, an email arrives in a Gmail label, or something happens on a GitHub repository: one run per event, filtered per watcher, never woken by its own writes, capped at 20 runs an hour, with every password and token kept in the vault.
**Architecture:** The core keeps the watchers in a new table `watchers` (migration 0013) behind `Store` (`store/watchers.rs`, with `watcher_fires` for the sliding-hour cap). `watchers::Watchers` (`watchers/mod.rs`) is a background service in the scheduler's pattern: one task per running watcher, a `reload()` that starts and stops them, the global pause, and `fire()`, the one door every event goes through (cap, staging, `Runner::enqueue` of a `TriggerKind::Watcher` run). The sources are `watchers/folder.rs` (`notify`, a 2-second settle per path, the acting rule checked when the OS reports the event), `watchers/email.rs` (Gmail over IMAP behind the `MailSource` trait; `EXAMINE` and `BODY.PEEK[]` only) and `watchers/github.rs` (REST polling with ETags). `watchers/acting.rs` holds which dots are acting: the runner tells it when it takes and lets go of a run. `watchers/files.rs` stages email attachments and the runner copies them into the run's workspace at prepare and removes them at the run's end. `watchers/describe.rs` writes the prompt's one-line trigger and the "Content from outside" section. The app wraps six runtime methods as commands and notifies once when a watcher pauses itself; the UI adds the editor's Watchers tab, the run labels, the Inbox list and the renamed pause switch.
**Tech Stack:** Rust 1.97 (sqlx SQLite, tokio, reqwest 0.12 rustls, wiremock 0.6 for tests), new: `notify` 8, `async-imap` 0.10 on tokio, `tokio-rustls` 0.26 on ring, `webpki-roots` 1, `mail-parser` 0.11, `futures-util` 0.3; Tauri 2.12; React 19.3, @tanstack/react-query 5.104, zod 4.6, radix-ui, lucide-react, Vitest 5.0 with Testing Library and the fake backend (`ui/src/test/backend.ts`); Bun 1.4.3.
**Spec:** docs/superpowers/specs/2026-10-23-watchers-design.md (sections 1 to 10; section 11 is decided below)

## Review Focus

The real-world failure modes most likely to bite a person that the spec's own tests do not cover, each pinned to the test that covers it:

1. **A cloud-synced folder (OneDrive, Dropbox) touches a file again after it settled.** The sync engine rewrites attributes or re-saves the same bytes seconds later, and Windows reports a change each time. Expected: one run per file; a later "change" whose size and modified time are what was last reported for that path is dropped. Test: `watchers_folder_test::a_file_touched_again_by_a_sync_engine_wakes_the_dot_once` (Task 3).
2. **The watched folder is deleted or renamed while Dots watches it** (a USB drive pulled, a OneDrive folder made online-only, the person renaming `Invoices`). ReadDirectoryChangesW then reports nothing ever again. Expected: the watcher pauses with `error` and "The folder <path> no longer exists.", shows in the Inbox and the app notifies once. Test: `watchers_folder_test::a_watched_folder_that_disappears_pauses_its_watcher` (Task 3).
3. **A Gmail label with spaces, accents or a `[Gmail]/` prefix.** IMAP names use modified UTF-7 and must be quoted. Expected: "Dots Été" is examined as `Dots &AMk-t&AOk-`, "日本" as `&ZeVnLA-`, "a&b" as `a&-b`; a label Gmail does not have pauses the watcher with "Gmail has no label <label>." Tests: `watchers_email_test::imap_names_use_modified_utf7`, `a_label_with_spaces_and_accents_is_examined_by_its_imap_name` (Task 4).
4. **IMAP's `UID n:*` answers the newest message even when nothing is newer, and UIDs jump.** A naive client re-runs the last email every minute, or walks a gap of thousands of UIDs one by one. Expected: a search past the newest UID fires nothing and fetches nothing; a jump from UID 3 to 9000 is one run and the cursor lands on 9000. Test: `watchers_email_test::a_search_past_the_newest_uid_fires_nothing_and_gaps_are_skipped` (Task 4).
5. **A fine-grained token that sees one of several repositories.** GitHub answers 404 (not 403) for a repository the token was not given. Expected: the events of the repositories it does see are handled first, then the watcher pauses with "The token in GITHUB_TOKEN cannot see owner/private."; after a resume nothing already handled runs again. Test: `watchers_github_test::a_repo_the_token_cannot_see_pauses_the_watcher_naming_it` (Task 6).

## Context

The scheduler (`crates/dots-core/src/scheduler.rs`) is the pattern for a background service: an `Arc` made at start, `spawn(shutdown)` running a loop that `select!`s on a `Notify` (`reload()`), the `Clock` (`sleep_until`) and the shutdown token; `set_paused` from `settings.schedules_paused` (`Runtime::change_settings`). Tests drive it with `tests/common/clock.rs`'s `FakeClock`. A run is queued with `Runner::enqueue(NewRun)`; the dispatcher starts at most one run per dot (`Store::dispatchable_runs`). The runner holds a run in its `active` map from before `claim_run` until after `after_finish` (`runner.rs` `dispatch_once`, `execute`): that span is exactly "acting" (spec §4.1). An approved call that Dots performs itself (an apply) is performed inside the resume run, so it is in that span too. The vault's `Vault::personal_value` (crate-visible) reads a secret and registers it with the global redactor (`vault::redact::global()`), and `Store::insert_run` scrubs every payload with that redactor.

Task 1 builds the table, the types and the checks; Task 2 the service, the cap, the acting tracker, the global pause, the Inbox list and the runtime methods; Tasks 3, 4 and 6 the three sources; Task 5 the attachments in runs; Task 7 the prompt; Task 8 the app and the UI's data layer; Task 9 the Watchers tab; Task 10 the run labels, the Inbox list and the Settings switch; Task 11 records the as-built notes.

```rust
            name: "Invoices folder".into(),

#[tokio::test]
async fn a_watcher_takes_at_most_20_fires_in_a_sliding_hour() {
    let (_dir, store) = temp_store().await;
    let dot = store.create_dot(&spec("busy")).await.unwrap();
    let w = store
        .add_watcher(&dot.id, "Busy", &folder("C:/in"))
        .await
        .unwrap();
    let hour = TimeDelta::hours(1);
    for i in 0..20 {
        let at = t0() + TimeDelta::minutes(i);
        assert!(store.take_fire(&w.id, at, hour, 20).await.unwrap(), "fire {i}");
    }
    assert!(!store
        .take_fire(&w.id, t0() + TimeDelta::minutes(20), hour, 20)
        .await
        .unwrap());
    // An hour and a second after the first fire, it has left the window: 19 remain.
    let later = t0() + hour + TimeDelta::seconds(1);
    assert!(store.take_fire(&w.id, later, hour, 20).await.unwrap());
    assert!(!store.take_fire(&w.id, later, hour, 20).await.unwrap());
    // The person's resume clears the count.
    store.clear_fires(&w.id).await.unwrap();
    for _ in 0..20 {
        assert!(store.take_fire(&w.id, later, hour, 20).await.unwrap());
    }
}
```

```rust
        .with_timezone(&Utc)

impl Harness {
    pub async fn new() -> Harness {
        Harness::with_sources(Sources::default()).await
    }

    pub async fn with_sources(sources: Sources) -> Harness {
        let (dir, store) = temp_store().await;
        let bus = new_bus();
        let clock = FakeClock::new(t0());
        let acting = ActingTracker::new(clock.clone());
        let vault = Vault::in_memory(store.clone());

        dir: &TempDir,
        store: &Store,
        bus: &Bus,
        clock: &Arc<FakeClock>,
        acting: &Arc<ActingTracker>,
        vault: &Vault,
        runner: &Arc<Runner>,
        sources: &Sources,

            store: store.clone(),
            bus: bus.clone(),
            runner: runner.clone(),
            vault: vault.clone(),
            clock: clock.clone(),
            acting: acting.clone(),
            data_dir: dir.path().join("data"),
            sources: sources.clone(),
        })
    }

    pub fn restart(&mut self) {
        self.shutdown.cancel();
        self.shutdown = CancellationToken::new();
        self.watchers = Harness::service(
            &self.dir, &self.store, &self.bus, &self.clock, &self.acting, &self.vault,
            &self.runner, &self.sources,
        );
    }

    /// Starts the service's loop (folder watches and polls run from here on).
    pub fn start(&self) {
        self.watchers.spawn(self.shutdown.clone());
    }

    pub async fn dot(&self, name: &str) -> Dot {
        self.store.create_dot(&spec(name)).await.unwrap()
    }

    pub async fn secret(&self, name: &str, value: &str) {
        self.vault.add(name, EntryKind::Secret, value).await.unwrap();
    }

    pub async fn watcher(&self, dot: &Dot, name: &str, config: WatcherConfig) -> Watcher {
        self.watchers.add(&dot.id, name, config).await.unwrap()
    }

    /// A folder under the harness's temp folder, made now.
    pub fn folder(&self, name: &str) -> std::path::PathBuf {
        let path = self.dir.path().join(name);
        std::fs::create_dir_all(&path).unwrap();
        path
    }

    /// The dot's watcher runs, oldest first.
    pub async fn runs(&self, dot_id: &str) -> Vec<Run> {
        let mut runs: Vec<Run> = self
            .store
            .list_runs(Some(dot_id), 500)
            .await
            .unwrap()
            .into_iter()
            .filter(|r| r.trigger == TriggerKind::Watcher)
            .collect();
        runs.reverse();
        runs
    }

    /// Waits (at most `secs` real seconds) until the dot has `n` watcher runs, and returns them.
    pub async fn wait_runs(&self, dot_id: &str, n: usize, secs: u64) -> Vec<Run> {
        let deadline = std::time::Instant::now() + Duration::from_secs(secs);
        loop {
            let runs = self.runs(dot_id).await;
            if runs.len() >= n {
                return runs;
            }
            assert!(
                std::time::Instant::now() < deadline,
                "{} watcher run(s) after {secs} s, not {n}",
                runs.len()
            );
            tokio::time::sleep(Duration::from_millis(50)).await;
        }
    }

    /// Waits `secs` real seconds and checks the dot still has exactly `n` watcher runs.
    pub async fn still(&self, dot_id: &str, n: usize, secs: u64) -> Vec<Run> {
        tokio::time::sleep(Duration::from_secs(secs)).await;
        let runs = self.runs(dot_id).await;
        assert_eq!(runs.len(), n, "{runs:#?}");
        runs
    }

    /// The `WatcherPaused` events since the last call: (watcher id, error).
    pub fn paused(&mut self) -> Vec<(String, Option<String>)> {
        let mut out = Vec::new();
        while let Ok(event) = self.events.try_recv() {
            if let RuntimeEvent::WatcherPaused { watcher_id, error, .. } = event {
                out.push((watcher_id, error));
            }
        }
        out
    }

    pub fn path_text(path: &Path) -> String {
        path.to_string_lossy().to_string()
    }
}

impl Drop for Harness {
    fn drop(&mut self) {
        self.shutdown.cancel();
    }
}
```

`watchers/folder.rs` watches a folder with `notify` from the moment the service starts the watcher (spec §4.1): it drops what is reported while the dot acts (checked in the OS's callback, at report time), settles each path for 2 seconds, then reports `created`, `changed` or `deleted` through `Watchers::fire`, subject to `events` and `pattern`. A vanished folder pauses the watcher. The fake CLI learns to write a file, so a real run can show that a dot's own write does not wake it.

**Interfaces:**

- Consumes: `Watchers::{fire, note_failure}`, `ActingTracker::is_acting`, `Clock::now`, `FolderConfig`, `watchers::folder_gone`, `globset`.
- Produces:
  - `watchers::folder::SETTLE: std::time::Duration = 2 s` (real time, `tokio::time`).
  - `watchers::folder::skipped(relative: &Path) -> bool`: true when any component of the path under the watched folder starts with `.`, or the file name ends (any case) with `.crdownload`, `.part`, `.tmp` or `.partial`, or starts with `~$` or `.~lock.`.
  - `watchers::folder::matches_pattern(pattern: &str, name: &str) -> bool`: an empty pattern matches every name; otherwise `globset::GlobBuilder::new(pattern).case_insensitive(true)` on the file name.
  - `pub(crate) fn folder::start(service: Weak<Watchers>, watcher: Watcher, config: FolderConfig, acting: Arc<ActingTracker>, clock: Arc<dyn Clock>, token: CancellationToken) -> Result<(), Failure>`: makes a `notify::RecommendedWatcher` on `config.path` (`RecursiveMode::Recursive` when `recursive`, else `NonRecursive`), returns once `watch` has returned, and keeps watching until `token` is cancelled. Its callback stamps `clock.now()` and drops the event when `acting.is_acting(dot_id, that time)`; otherwise it sends it to a tokio task. The task keeps, per path, the first kind seen and a deadline (`SETTLE` after the latest event); every second it reports the paths whose deadline passed, and checks that `config.path` is still a folder (else `note_failure(Permanent(folder_gone(path)))`, and it ends). A rename's old name is a removal, its new name a creation. At the deadline: a path that is a folder is remembered and skipped; a path that exists is `created` when the first kind seen was a creation, else `changed`; a path that does not exist is `deleted`, unless it was first created in this window or is a remembered folder. Folders are remembered from a walk at start (at most 20,000 entries) and from each settled one. A `changed` whose size and modified time equal the last reported for that path is dropped. Then `skipped`, `matches_pattern` (file name) and `events` filter, and a non-recursive watcher drops paths below a subfolder. The payload: `{"source": "folder", "event", "path": <config.path joined with the relative path, as text>, "relative": <the path under the folder, with the OS's separators>, "size": <bytes, or null when deleted>}`.

  - The fake CLI's script step `{"write": {"path": "<relative to its cwd>", "text": "…"}}`.

### Task 4: Email watchers (Gmail over IMAP, read-only)

```rust
//! A Gmail mailbox in memory for email watchers (watchers spec section 4.2). It records each
//! command as the IMAP client would send it, so a test sees that nothing is ever written, and it
//! answers `UID n:*` past the newest mail with the newest one, as IMAP servers do.

use std::sync::{Arc, Mutex};

use async_trait::async_trait;
use base64::Engine as _;
use dots_core::watchers::email::{login_refused, FolderState, MailSource, Mailbox};
use dots_core::watchers::Failure;

#[derive(Default)]
struct Folder {
    uid_validity: u32,
    mails: BTreeMap<u32, Vec<u8>>,
}

#[derive(Default)]
struct State {
    password: String,
    folders: BTreeMap<String, Folder>,
    commands: Vec<String>,
    fail: Option<Failure>,
}

#[derive(Clone)]
pub struct FakeMail {
    state: Arc<Mutex<State>>,
}

impl FakeMail {
    /// A mailbox whose app password is `password`, with an empty INBOX (UIDVALIDITY 1).
    pub fn new(password: &str) -> FakeMail {
        let state = State { password: password.into(), ..State::default() };
        let fake = FakeMail { state: Arc::new(Mutex::new(state)) };
        fake.folder("INBOX", 1);
        fake
    }

    /// Makes the folder `name` (its IMAP name) with `uid_validity`.
    pub fn folder(&self, name: &str, uid_validity: u32) {
        let folder = Folder { uid_validity, mails: BTreeMap::new() };
        self.state.lock().unwrap().folders.insert(name.into(), folder);
    }

    /// Puts `mail` into `folder` under the next UID, and returns the UID.
    pub fn deliver(&self, folder: &str, mail: Vec<u8>) -> u32 {
        let mut s = self.state.lock().unwrap();
        let f = s.folders.get_mut(folder).expect("a folder");
        let uid = f.mails.keys().last().copied().unwrap_or(0) + 1;
        f.mails.insert(uid, mail);
        uid
    }

    pub fn deliver_as(&self, folder: &str, uid: u32, mail: Vec<u8>) {
        self.state.lock().unwrap().folders.get_mut(folder).unwrap().mails.insert(uid, mail);
    }

    pub fn set_uid_validity(&self, folder: &str, uid_validity: u32) {
        self.state.lock().unwrap().folders.get_mut(folder).unwrap().uid_validity = uid_validity;
    }

    /// The next connect fails with `failure`.
    pub fn fail_next(&self, failure: Failure) {
        self.state.lock().unwrap().fail = Some(failure);
    }

    pub fn commands(&self) -> Vec<String> {
        self.state.lock().unwrap().commands.clone()
    }

    pub fn clear_commands(&self) {
        self.state.lock().unwrap().commands.clear();
    }
}

#[async_trait]
impl MailSource for FakeMail {
    async fn connect(&self, address: &str, password: &str) -> Result<Box<dyn Mailbox>, Failure> {
        let mut s = self.state.lock().unwrap();
        s.commands.push(format!("LOGIN {address}"));
        if let Some(failure) = s.fail.take() {
            return Err(failure);
        }
        if password != s.password {
            return Err(Failure::Permanent(login_refused(address)));
        }
        Ok(Box::new(Session { state: self.state.clone(), folder: String::new() }))
    }
}

struct Session {
    state: Arc<Mutex<State>>,
    folder: String,
}

#[async_trait]
impl Mailbox for Session {
    async fn examine(&mut self, folder: &str) -> Result<Option<FolderState>, Failure> {
        let mut s = self.state.lock().unwrap();
        s.commands.push(format!("EXAMINE {folder}"));
        self.folder = folder.into();
        Ok(s.folders.get(folder).map(|f| FolderState {
            uid_validity: f.uid_validity,
            uid_next: f.mails.keys().last().copied().unwrap_or(0) + 1,
        }))
    }

    async fn search_from(&mut self, first_uid: u32) -> Result<Vec<u32>, Failure> {
        let mut s = self.state.lock().unwrap();
        s.commands.push(format!("UID SEARCH UID {first_uid}:*"));
        let f = &s.folders[&self.folder];
        let mut uids: Vec<u32> = f.mails.keys().copied().filter(|u| *u >= first_uid).collect();
        if uids.is_empty() {
            uids.extend(f.mails.keys().last().copied());
        }
        Ok(uids)
    }

    async fn fetch(&mut self, uid: u32) -> Result<Vec<u8>, Failure> {
        let mut s = self.state.lock().unwrap();
        s.commands.push(format!("UID FETCH {uid} BODY.PEEK[]"));
        Ok(s.folders[&self.folder].mails[&uid].clone())
    }

    async fn logout(&mut self) {
        self.state.lock().unwrap().commands.push("LOGOUT".into());
    }
}

pub fn mail(spec: MailSpec) -> Vec<u8> {

    let kind = if spec.html { "text/html" } else { "text/plain" };
    let mut out = format!(
        "From: {}\r\nTo: me@gmail.com\r\nSubject: {}\r\nDate: Fri, 23 Oct 2026 09:00:00 +0000\r\n\
         Message-ID: <{}>\r\nMIME-Version: 1.0\r\nContent-Type: multipart/mixed; boundary=\"b0\"\r\n\r\n\

    );

             Content-Disposition: attachment; filename=\"{name}\"\r\n\r\n{}\r\n",
```

```rust
//! The real IMAP client (watchers spec section 4.2) against a scripted local server: it logs
//! in, examines, searches and fetches with BODY.PEEK[], and sends no command that could change
//! the mailbox; a refused login is permanent and an unreachable server transient.

use std::sync::{Arc, Mutex};

use dots_core::watchers::email::{FolderState, ImapMailSource, MailSource};
use dots_core::watchers::Failure;
use tokio::io::{AsyncBufReadExt, AsyncWriteExt, BufReader};
use tokio::net::TcpListener;

const MAIL: &[u8] = b"From: a@acme.com\r\nSubject: Hi\r\n\r\nHello\r\n";

/// Serves one connection, answering each command by its verb; returns the port and the
/// commands it was sent (without their tags).
async fn server(refuse_login: bool) -> (u16, Arc<Mutex<Vec<String>>>) {
    let listener = TcpListener::bind("127.0.0.1:0").await.unwrap();
    let port = listener.local_addr().unwrap().port();
    let lines = Arc::new(Mutex::new(Vec::new()));
    let seen = lines.clone();
    tokio::spawn(async move {
        let (socket, _) = listener.accept().await.unwrap();
        let (read, mut write) = socket.into_split();
        let mut read = BufReader::new(read);
        write.write_all(b"* OK IMAP4rev1 ready\r\n").await.unwrap();
        let mut line = String::new();
        while read.read_line(&mut line).await.unwrap() > 0 {
            let text = line.trim_end().to_string();
            line.clear();
            let (tag, command) = text.split_once(' ').unwrap_or((&text, ""));
            let verb = command.to_ascii_uppercase();
            seen.lock().unwrap().push(command.to_string());
            let answer = if verb.starts_with("LOGIN") && refuse_login {
                format!("{tag} NO [AUTHENTICATIONFAILED] Invalid credentials\r\n")
            } else if verb.starts_with("CAPABILITY") {
                format!("* CAPABILITY IMAP4rev1\r\n{tag} OK done\r\n")
            } else if verb.starts_with("EXAMINE") {
                format!("* 2 EXISTS\r\n* OK [UIDVALIDITY 7] ok\r\n* OK [UIDNEXT 3] ok\r\n{tag} OK [READ-ONLY] done\r\n")
            } else if verb.starts_with("UID SEARCH") {
                format!("* SEARCH 1 2\r\n{tag} OK done\r\n")
            } else if verb.starts_with("UID FETCH") {
                let mut out = format!("* 2 FETCH (UID 2 BODY[] {{{}}}\r\n", MAIL.len()).into_bytes();
                out.extend_from_slice(MAIL);
                out.extend_from_slice(format!(")\r\n{tag} OK done\r\n").as_bytes());
                write.write_all(&out).await.unwrap();
                continue;
            } else if verb.starts_with("LOGOUT") {
                write.write_all(format!("* BYE\r\n{tag} OK done\r\n").as_bytes()).await.unwrap();
                break;
            } else {
                format!("{tag} OK done\r\n")
            };
            write.write_all(answer.as_bytes()).await.unwrap();
        }
    });
    (port, lines)
}
```

**Interfaces:**

- Consumes: `Sources.github_api`, `reqwest`, `Vault::personal_value`, `Watchers::{fire, note_failure, note_success}`, `Store::{get_watcher_cursor, set_watcher_cursor}`, `watchers::{entry_gone, MAX_BODY_CHARS, POLL_EVERY}`.
