# A Chat-First Home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dots opens on a conversation with your dots: a column of dots like chat contacts, and the open dot's conversation, where its chat topic and the runs a schedule, a webhook or Run now started after it are read, answered and replied to in time order; the Dots table and the Chat screen go.
**Architecture:** Pure logic in `ui/src/lib/home-topics.ts` (a dot's runs as topics: lines of runs by `root_run_id`; the conversation, History, the default reply target, titles) and `ui/src/lib/dot-status.ts` (the column's status mark, order, last line and next fire). The screen lives in `ui/src/screens/home/`: `HomeScreen` (the route element: column plus pane, `/home` opening the dot last opened), `DotsColumn`, `DotPane` (header, timeline, reply area for one dot or one older topic), `use-conversation.ts` (`list_runs(dotId, 200)`, one `run_thread` per topic shown, `messages_list(dotId)`), `Timeline` (chat topics as `TopicRuns`, the existing `Transcript` reused; run topics as `RunCard`; stick-to-bottom), `ReplyArea` (reply target chip, open-question bar, `Composer`), `HistoryMenu` and `DotMenu` (Radix dropdown menus), `ChatRedirect` (the old `/chat/...` addresses). `app/routes.tsx` and `app/Layout.tsx` (an icon rail) change last, with the removal of `ChatScreen`, `DotsScreen` and `chat-threads.ts`.
**Tech Stack:** React 19.3, react-router 8.4 (hash router; memory router in tests), @tanstack/react-query 5.104, Tailwind 4.3 with the existing shadcn components, `radix-ui` 1.8 (`DropdownMenu`, already a dependency), lucide-react 1.55, zod 4.6; Vitest 5.0 with Testing Library and the fake backend (`ui/src/test/backend.ts`); Bun 1.4.3. No Rust change.
**Spec:** docs/superpowers/specs/2026-10-22-chat-home-design.md (sections 1 to 9; section 10 is out of scope)

## Review Focus

The inputs and failure modes the spec implies that are most likely to bite a person using the home first, each pinned to the test that covers it:

1. **A reply that goes to a line the screen no longer holds.** A second window or a stale screen sends to a topic that has a newer run, or whose run still works; the core refuses with its own sentence. Expected: the sentence is shown, the text stays in the composer, the topics are loaded again, nothing more can be sent until they are, and the next try continues the run the topic really ends with. Tests: `Sending.test.tsx > loads the topics again after a refusal and replies to the run the topic ends with` and `keeps the composer locked after a send until the topics have reloaded` (Task 4).
2. **The reply target moving under the person.** A scheduled run lands after the current topic; Reply on a card, then ✕; New topic, then ✕, then a send; a topic whose last run ended before it had a session. Expected: the chip always names the topic the next message continues, the default is the topic with the newest run, a send returns to the default, and a closed topic offers New topic instead of a send the core would refuse. Tests: `Sending.test.tsx > replies by default to a scheduled run that came after the current topic`, `replies to the run topic whose Reply was pressed, until ✕`, `starts a new topic, which becomes the current one`, `says that a topic whose last run ended without a session cannot be continued` (Task 4).
3. **Where the home opens.** The dot last opened was deleted; the open dot is deleted; there is no dot; an old `/chat/...` link (the tray's, a bookmark) names a run of an older topic, or a run that is gone. Expected: the first dot of the column, the empty home with its button, the older topic alone, the dot's conversation. Tests: `HomeColumn.test.tsx > forgets a dot last opened that no longer exists`, `goes back to the home when the open dot is deleted`, `offers to create the first dot when there is none` (Task 2); `HomeRoutes.test.tsx > opens an old chat's topic in the conversation, or alone when it is older` and `opens the dot's conversation for an old chat address of a run that is gone` (Task 6).
4. **Many runs.** A dot that only ever ran on a schedule (25 run topics, no chat); 60 chat topics; a topic whose root is older than the 200 runs loaded. Expected: the last 20 run topics; History's 50 newest; the topic still shown, named by its oldest loaded run. Tests: `home-topics.test.ts > shows the last 20 run topics of a dot that has no chat topic`, `lists 50 older topics at most`, `takes the oldest loaded run as the root when the root is older than what was loaded` (Task 1); `Conversation.test.tsx > shows the last 20 run topics of a dot that never chatted` (Task 3).
5. **Activity while the person reads.** A scheduled run fires while they scrolled up; a run's status changes; a card that stays closed; a question answered in the Inbox. Expected: no jump while scrolled up, "New activity ↓" instead; statuses change in place; a closed card loads no events; the question bar goes. Tests: `Conversation.test.tsx > follows new activity at the bottom, and offers it after the person scrolled up`, `adds a new run of the dot at the end, and changes a status in place`, `shows a closed run card without loading its events` (Task 3); `OpenConversation.test.tsx > drops the conversation's question bar when the question is answered in the Inbox` (Task 7).

**Create `ui/src/lib/home-topics.test.ts`:**

```ts
import { describe, expect, it } from "vitest";

import type { Run } from "@/api/types";
import { localTime } from "@/lib/format";
import {
  conversation,
  currentTopic,
  defaultTarget,
  olderTopics,
  oneLine,
  topicOf,
  topicsOf,
  topicTitle,
} from "@/lib/home-topics";
import { sample } from "@/test/fixtures";

/// A root run queued at `at` (minutes after 10:00 on 9 October); a chat run unless `over` says.
const root = (id: string, at: number, over: Partial<Run> = {}): Run => ({
  ...sample.run,
  id,
  root_run_id: id,
  parent_run_id: null,
  trigger: "chat",
  payload: { message: `message of ${id}` },
  queued_at: new Date(Date.UTC(2026, 9, 9, 10, at)).toISOString(),
  ...over,
});
/// A run that continued `parent`, queued at `at`.
const reply = (id: string, parent: Run, at: number): Run =>
  root(id, at, { root_run_id: parent.root_run_id, parent_run_id: parent.id });
const ids = (topics: { rootId: string }[]) => topics.map((t) => t.rootId);

describe("topics", () => {
  it("groups runs into lines by their root, ordered by the roots' queue times", () => {
    const a = root("a", 0);
    const cron = root("cron", 5, { trigger: "schedule", payload: null });
    const b = root("b", 10);
    const topics = topicsOf([b, reply("a2", a, 20), cron, a, reply("cron1", cron, 30)]);
    expect(ids(topics)).toEqual(["a", "cron", "b"]);
    expect(topics.map((t) => t.kind)).toEqual(["chat", "run", "chat"]);
    expect(topics[0].runs.map((r) => r.id)).toEqual(["a", "a2"]);
    expect(topics[1].runs.map((r) => r.id)).toEqual(["cron", "cron1"]);
  });

  it("takes the oldest loaded run as the root when the root is older than what was loaded", () => {
    const gone = root("gone", 0, { trigger: "schedule" });
    const topic = topicOf([reply("r2", gone, 20), reply("r1", gone, 10)]);
    expect(topic.rootId).toBe("gone");
    expect(topic.root.id).toBe("r1");
    // The oldest run left is a reply, a chat run: the line reads as a chat.
    expect(topic.kind).toBe("chat");
  });

  it("makes the newest chat topic current, with the run topics after it", () => {
    const old = root("old", 0);
    const before = root("before", 5, { trigger: "schedule" });
    const current = root("current", 10);
    const after = root("after", 15, { trigger: "webhook" });
    const manual = root("manual", 20, { trigger: "manual" });
    const topics = topicsOf([old, before, current, after, manual, reply("old2", old, 30)]);
    expect(currentTopic(topics)?.rootId).toBe("current");
    expect(ids(conversation(topics))).toEqual(["current", "after", "manual"]);
    // History: everything else, newest first.
    expect(ids(olderTopics(topics, conversation(topics)))).toEqual(["before", "old"]);
  });

  it("shows the last 20 run topics of a dot that has no chat topic", () => {
    const runs = Array.from({ length: 25 }, (_, i) =>
      root(`r${String(i).padStart(2, "0")}`, i, { trigger: "schedule" }),
    );
    const topics = topicsOf(runs);
    expect(currentTopic(topics)).toBeUndefined();
    const shown = conversation(topics);
    expect(shown).toHaveLength(20);
    expect(shown[0].rootId).toBe("r05");
    expect(shown.at(-1)!.rootId).toBe("r24");
    expect(ids(olderTopics(topics, shown))).toEqual(["r04", "r03", "r02", "r01", "r00"]);
  });

  it("lists 50 older topics at most", () => {
    const runs = Array.from({ length: 60 }, (_, i) => root(`c${String(i).padStart(2, "0")}`, i));
    const topics = topicsOf(runs);
    const older = olderTopics(topics, conversation(topics));
    expect(older).toHaveLength(50);
    expect(older[0].rootId).toBe("c58");
  });

  it("replies by default to the shown topic with the newest run", () => {
    const current = root("current", 0);
    const cron = root("cron", 10, { trigger: "schedule" });
    expect(defaultTarget(topicsOf([current, cron]))?.rootId).toBe("cron");
    // A reply in the current topic after the scheduled run makes it the newest again.
    expect(defaultTarget(topicsOf([current, cron, reply("c2", current, 20)]))?.rootId).toBe(
      "current",
    );
    expect(defaultTarget([])).toBeUndefined();
  });

  it("names a chat topic by its first line and a run topic by its trigger and time", () => {
    const named = (over: Partial<Run>) => topicTitle(topicOf([root("a", 0, over)]));
    expect(named({ payload: { message: "  Fix the bug\nand add a test" } })).toBe("Fix the bug");
    expect(named({ payload: { message: "x".repeat(100) } })).toBe(`${"x".repeat(60)}…`);
    expect(named({ payload: { message: "" } })).toBe("Chat");
    const at = root("a", 0).queued_at;
    expect(named({ trigger: "schedule", payload: null })).toBe(`Scheduled · ${localTime(at)}`);
    expect(named({ trigger: "webhook", payload: null })).toBe(`Webhook · ${localTime(at)}`);
    expect(named({ trigger: "manual", payload: null })).toBe(`Run now · ${localTime(at)}`);
  });

  it("cuts text to its first line", () => {
    expect(oneLine(" one\ntwo ")).toBe("one");
    expect(oneLine(null)).toBe("");
    expect(oneLine("abcdef", 3)).toBe("abc…");
  });
});
```

```ts
// A dot's runs as topics, and which of them make its conversation on the home (chat-first home
// spec, section 2).
import type { Run } from "@/api/types";
import { localTime } from "@/lib/format";

/// One line of runs: a root run and the runs that continued it (`root_run_id`).
export type Topic = {
  /// The root's id: the topic's name in the address.
  rootId: string;
  /// The topic's oldest run known here: its root, or the oldest run of it that was loaded when
  /// the root is older than what was loaded.
  root: Run;
  /// Its runs, oldest first.
  runs: Run[];
  /// "chat" when the root is a chat run; "run" when a schedule, a webhook, Run now or a
  /// follow-up started it.
  kind: "chat" | "run";
};

/// How many run topics make the conversation of a dot that has no chat topic.
export const RUN_TOPICS = 20;
/// How many older topics History lists at most.
export const HISTORY = 50;

/// Whether the run has not ended: it waits to start, runs, or waits for an approval. The one
/// definition for every screen (the core's is `RunStatus::is_terminal`).
export function isActive(run: Run): boolean {
  return run.status === "queued" || run.status === "running" || run.status === "awaiting_approval";
}

const byQueued = (a: Run, b: Run) => a.queued_at.localeCompare(b.queued_at);

/// The topic of one line of runs, given in any order and none missing between them.
export function topicOf(runs: Run[]): Topic {
  const sorted = [...runs].sort(byQueued);
  const root = sorted.find((run) => run.id === run.root_run_id) ?? sorted[0];
  return {
    rootId: sorted[0].root_run_id,
    root,
    runs: sorted,
    kind: root.trigger === "chat" ? "chat" : "run",
  };
}

/// A dot's runs as topics, ordered by the time their roots were queued, oldest first.
export function topicsOf(runs: Run[]): Topic[] {
  const lines = new Map<string, Run[]>();
  for (const run of runs) {
    const line = lines.get(run.root_run_id) ?? [];
    line.push(run);
    lines.set(run.root_run_id, line);
  }
  return [...lines.values()].map(topicOf).sort((a, b) => byQueued(a.root, b.root));
}

/// The newest chat topic, by the time its root was queued.
export function currentTopic(topics: Topic[]): Topic | undefined {
  return topics.filter((topic) => topic.kind === "chat").at(-1);
}

/// The topics of the conversation, oldest first: the current topic and every run topic whose
/// root was queued after its root; with no chat topic, the last `RUN_TOPICS` run topics.
export function conversation(topics: Topic[]): Topic[] {
  const current = currentTopic(topics);
  if (current === undefined) return topics.slice(-RUN_TOPICS);
  return topics.filter(
    (topic) =>
      topic === current ||
      (topic.kind === "run" && topic.root.queued_at.localeCompare(current.root.queued_at) > 0),
  );
}

/// The topics History lists: those not in the conversation, newest first, `HISTORY` at most.
export function olderTopics(topics: Topic[], shown: Topic[]): Topic[] {
  const inConversation = new Set(shown.map((topic) => topic.rootId));
  return topics
    .filter((topic) => !inConversation.has(topic.rootId))
    .reverse()
    .slice(0, HISTORY);
}

/// The newest run of a topic: what a reply continues.
export function lastRun(topic: Topic): Run {
  return topic.runs.at(-1)!;
}

/// The topic a message goes to by default: of the topics shown, the one with the newest run.
export function defaultTarget(shown: Topic[]): Topic | undefined {
  let target: Topic | undefined;
  for (const topic of shown) {
    if (target === undefined || byQueued(lastRun(target), lastRun(topic)) <= 0) target = topic;
  }
  return target;
}

const TRIGGER: Record<Run["trigger"], string> = {
  schedule: "Scheduled",
  webhook: "Webhook",
  manual: "Run now",
  chat: "Chat",
  resume: "Continued",
  follow_up: "Follow-up",
};

/// What started a run, in a word or two: "Scheduled", "Webhook", "Run now".
export function triggerLabel(run: Run): string {
  return TRIGGER[run.trigger];
}

/// The first line of a string, trimmed and cut to `max` characters; "" for none.
export function oneLine(text: string | null | undefined, max = 80): string {
  const line = (text ?? "").trim().split("\n")[0].trim();
  return line.length > max ? `${line.slice(0, max)}…` : line;
}

/// What the person wrote to start a chat run: an answer as they typed it, else the message.
export function chatText(run: Run): string | null {
  if (typeof run.payload !== "object" || run.payload === null) return null;
  const { answer, message } = run.payload as Record<string, unknown>;
  if (typeof answer === "string") return answer;
  return typeof message === "string" ? message : null;
}

/// A topic's name: the first line of its root's message for a chat topic, else its trigger and
/// the time it was queued ("Scheduled · 08:00").
export function topicTitle(topic: Topic): string {
  if (topic.kind === "chat") return oneLine(chatText(topic.root), 60) || "Chat";
  return `${triggerLabel(topic.root)} · ${localTime(topic.root.queued_at)}`;
}
```

```ts
// What the home's column says about each dot (chat-first home spec, section 3).
import type { DotOverview, FollowUp, Message } from "@/api/types";
import { localTime, relativeTime } from "@/lib/format";
import { chatText, oneLine } from "@/lib/home-topics";
import { isOpenQuestion } from "@/lib/messages";

/// A dot's status mark, in the order the first match wins.
export type DotStatus = "waiting" | "running" | "attention" | "off" | "idle";

export const STATUS_LABEL: Record<DotStatus, string> = {
  waiting: "waiting for you",
  running: "running",
  attention: "needs attention",
  off: "off",
  idle: "idle",
};

/// Waiting (a run waits for an approval, or the dot asked a question still open), running (a
/// run is queued or running), attention (its schedule needs attention), off (disabled), else
/// idle. `messages`: any messages; only the dot's open questions count.
export function dotStatus(row: DotOverview, messages: Message[]): DotStatus {
  const active = row.active_run;
  if (
    active?.status === "awaiting_approval" ||
    messages.some((m) => m.dot_id === row.dot.id && isOpenQuestion(m))
  ) {
    return "waiting";
  }
  if (active?.status === "queued" || active?.status === "running") return "running";
  if (row.schedule_state?.attention) return "attention";
  if (!row.dot.enabled) return "off";
  return "idle";
}

/// When the dot last did something: the later of its active and last runs' queue times.
function activity(row: DotOverview): string | null {
  const times = [row.active_run?.queued_at, row.last_run?.queued_at].filter(
    (t): t is string => typeof t === "string",
  );
  return times.length === 0 ? null : times.sort().at(-1)!;
}

/// The column's order: newest activity first; the dots that never ran after them, by name.
export function sortDots(rows: DotOverview[]): DotOverview[] {
  return [...rows].sort((a, b) => {
    const [x, y] = [activity(a), activity(b)];
    if (x !== null && y !== null) return y.localeCompare(x);
    if (x !== null) return -1;
    if (y !== null) return 1;
    return a.dot.name.localeCompare(b.dot.name);
  });
}

/// The row's last line: the last run's summary, else its error, else its chat message, on one
/// line; "" without a last run.
export function lastLine(row: DotOverview): string {
  const run = row.last_run;
  if (run === null) return "";
  return oneLine(run.summary) || oneLine(run.error) || oneLine(chatText(run));
}

/// "next 02:00" for the next scheduled fire, else when the dot's next follow-up fires ("Next
/// follow-up in 3 h"), else "". `followUps`: the pending ones of every dot, soonest first.
export function nextLine(row: DotOverview, followUps: FollowUp[]): string {
  const fire = row.schedule_state?.next_fire;
  if (fire) return `next ${localTime(fire)}`;
  const followUp = followUps.find((f) => f.dot_id === row.dot.id);
  return followUp ? `Next follow-up ${relativeTime(followUp.due_at)}` : "";
}
```

```ts
/// Where the home keeps the dot last opened, so that it opens on it next time.
const KEY = "dots.home.dot";

/// The dot last opened, or null. Storage that cannot be read counts as empty.
export function lastDot(): string | null {
  try {
    return window.localStorage.getItem(KEY);
  } catch {
    return null;
  }
}

/// Remembers `dotId` as the dot last opened; storage that cannot be written is left alone.
export function rememberDot(dotId: string): void {
  try {
    window.localStorage.setItem(KEY, dotId);
  } catch {
    // Opening the first dot next time is fine.
  }
}
```

```tsx
/// `rows` come sorted; `openId` is the dot whose conversation is open.
export function DotsColumn({ rows, openId }: { rows: DotOverview[]; openId: string | undefined }) {
  const navigate = useNavigate();
  // Every dot's open questions mark it as waiting; the frame loads the same list for its count.
  const messages =
    useQuery({ queryKey: keys.messages(null), queryFn: () => commands.messagesList(null) }).data ??
    [];
  const followUps =
    useQuery({
      queryKey: keys.followUps(null),
      queryFn: () => commands.followUpsList(null),
    }).data ?? [];
  // Up and Down open the dot above or below the one in focus, or the open one.
  function onKeyDown(e: KeyboardEvent<HTMLUListElement>) {
    if (e.key !== "ArrowDown" && e.key !== "ArrowUp") return;
    e.preventDefault();
    const links = [...e.currentTarget.querySelectorAll<HTMLAnchorElement>("a[data-dot]")];
    const focused = links.indexOf(document.activeElement as HTMLAnchorElement);
    const from = focused !== -1 ? focused : rows.findIndex((row) => row.dot.id === openId);
    const to = Math.min(rows.length - 1, Math.max(0, from + (e.key === "ArrowDown" ? 1 : -1)));
    links[to]?.focus();
    if (rows[to] && rows[to].dot.id !== openId) void navigate(`/home/${rows[to].dot.id}`);
```

```ts
// A dot and its runs for the home's tests: the fake backend answers the home's commands from
// the runs, the events and the approvals a test gives, as the core would.
import type { Approval, DotOverview, Run, RunEventRecord } from "@/api/types";

import { backend } from "./backend";
import { sample } from "./fixtures";

export const dot = { ...sample.dot, schedule: null };

/// The dot's row in the column: idle, with no run.
export const overview: DotOverview = {
  dot,
  active_run: null,
  last_run: null,
  schedule_state: null,
};

/// A root run of the dot queued at `at` ("HH:MM" on 9 October, UTC): a chat run asking
/// "question <id>" that succeeded, unless `over` says otherwise.
export const chat = (id: string, at: string, over: Partial<Run> = {}): Run => ({
  ...sample.run,
  id,
  dot_id: dot.id,
  root_run_id: id,
  parent_run_id: null,
  trigger: "chat",
  branch: null,
  summary: null,
  payload: { message: `question ${id}` },
  queued_at: `2026-10-09T${at}:00.000Z`,
  ...over,
});

/// A scheduled root run of the dot queued at `at` that succeeded with `summary`.
export const scheduled = (id: string, at: string, over: Partial<Run> = {}): Run =>
  chat(id, at, { trigger: "schedule", payload: null, summary: `Summary of ${id}`, ...over });

/// A chat run that continued `parent`, queued at `at`.
export const reply = (id: string, parent: Run, at: string, over: Partial<Run> = {}): Run =>
  chat(id, at, {
    root_run_id: parent.root_run_id,
    parent_run_id: parent.id,
    payload: { message: `reply ${id}` },
    ...over,
  });

/// The dot said `text` in run `runId`.
export const said = (runId: string, seq: number, text: string): RunEventRecord => ({
  run_id: runId,
  seq,
  ts: sample.run.queued_at,
  kind: "assistant_text",
  data: { kind: "assistant_text", text },
});

/// A backend holding the dot and `runs` (changed in place by the test or by `chat`, which
/// appends a queued run as the core does). Answers the column, the runs, the threads, the
/// events and the approvals.
export function home(runs: Run[], events: RunEventRecord[] = [], approvals: Approval[] = []) {
  const all = [...runs];
  backend.on("dot_overview", () => [overview]);
  backend.on("list_dots", () => [dot]);
  backend.on("list_runs", () => [...all].reverse());
  backend.on("run_thread", (args) => {
    const root = all.find((r) => r.id === args.runId)?.root_run_id;
    return all.filter((r) => r.root_run_id === root);
  });
  backend.on("list_run_events", (args) =>
    events.filter((e) => e.run_id === args.runId && e.seq > (args.afterSeq as number)),
  );
  backend.on("approvals_for_run", (args) => approvals.filter((a) => a.run_id === args.runId));
  backend.on("chat", (args) => {
    const parent = all.find((r) => r.id === args.parentRunId);
    const id = `run-${all.length + 1}`;
    // Each one a minute after the one before.
    const run = chat(id, `15:${String(all.length).padStart(2, "0")}`, {
      status: "queued",
      ended_at: null,
      payload: { message: args.message },
      parent_run_id: parent?.id ?? null,
      root_run_id: parent?.root_run_id ?? id,
    });
    all.push(run);
    return run;
  });
  return all;
}
```

**Create `ui/src/lib/use-stick-to-bottom.ts`:**

```ts
import { useEffect, useRef, useState } from "react";

/// How close to the bottom, in pixels, still counts as at the bottom.
const SLACK = 32;

/// Keeps a scrolling element at its bottom while what is in it grows, unless the person has
/// scrolled up; then `behind` is true until they come back down or `jump` takes them there.
/// The element given `ref` must be mounted with the component.
export function useStickToBottom<T extends HTMLElement>() {
  const ref = useRef<T>(null);
  const stuck = useRef(true);
  const [behind, setBehind] = useState(false);
  useEffect(() => {
    const element = ref.current;
    if (element === null) return;
    element.scrollTop = element.scrollHeight;
    const observer = new MutationObserver(() => {
      if (stuck.current) element.scrollTop = element.scrollHeight;
      else setBehind(true);
    });
    observer.observe(element, { childList: true, subtree: true, characterData: true });
    return () => observer.disconnect();
  }, []);
  function onScroll() {
    const element = ref.current;
    if (element === null) return;
    stuck.current = element.scrollHeight - element.scrollTop - element.clientHeight <= SLACK;
    if (stuck.current) setBehind(false);
  }
  function jump() {
    const element = ref.current;
    if (element === null) return;
    element.scrollTop = element.scrollHeight;
    stuck.current = true;
    setBehind(false);
  }
  return { ref, onScroll, behind, jump };
}
```

```ts
import { useQueries, useQuery } from "@tanstack/react-query";

import { commands } from "@/api/commands";
import {
  conversation,
  olderTopics,
  topicOf,
  topicsOf,
  type Topic,
} from "@/lib/home-topics";
import { keys } from "@/lib/query";

/// How many of the dot's newest runs the home loads; older ones are reached through History.
export const LOADED_RUNS = 200;

/// What a dot's side of the home shows (chat-first home spec, section 4.3): the dot's topics
/// from its newest runs; the topics shown, each loaded whole with `run_thread` (the
/// conversation, or the older topic `rootRunId` alone); the topics History offers; and the
/// dot's notes and questions, oldest first.
export function useConversation(dotId: string, rootRunId: string | undefined) {
  const list = useQuery({
    // Its own key under "runs": the dot editor lists the same dot's runs with another limit.
    queryKey: [...keys.runs(dotId), "home"],
    queryFn: () => commands.listRuns(dotId, LOADED_RUNS),
  });
  const topics = topicsOf(list.data ?? []);
  const current = conversation(topics);
  const roots = rootRunId !== undefined ? [rootRunId] : current.map((topic) => topic.rootId);
  const threads = useQueries({
    queries: roots.map((root) => ({
      queryKey: keys.thread(root),
      queryFn: () => commands.runThread(root),
    })),
  });
  // A thread on its way shows as far as the list has it.
  const shown: Topic[] = roots.flatMap((root, i) => {
    const runs = threads[i]?.data ?? topics.find((topic) => topic.rootId === root)?.runs ?? [];
    return runs.length === 0 ? [] : [topicOf(runs)];
  });
  const messages = useQuery({
    queryKey: keys.messages(dotId),
    queryFn: () => commands.messagesList(dotId),
  });
  const checkIns = [...(messages.data ?? [])].sort((a, b) =>
    a.created_at.localeCompare(b.created_at),
  );
  return {
    list,
    threads,
    shown,
    older: olderTopics(topics, current),
    checkIns,
    /// Nothing to show yet: the list, or the older topic, is still on its way.
    pending: list.isPending || (rootRunId !== undefined && threads[0]?.isPending === true),
  };
}
```

```tsx
import { useQueries, useQueryClient } from "@tanstack/react-query";

import { commands } from "@/api/commands";
import type { Message, Run, RunEventRecord } from "@/api/types";
import { AppliedCalls } from "@/components/AppliedCalls";
import { ApprovalCard } from "@/components/ApprovalCard";
import { LoadErrors } from "@/components/ErrorNote";
import { Transcript } from "@/components/Transcript";
import { eventsQuery, keys } from "@/lib/query";

/// Runs of one topic as the chat shows a thread: each run's message, the dot's text, its tool
/// steps, check-ins and browser calls (`Transcript`), the calls Dots performed, a card per
/// approval it waits for, and why the last run failed.
export function TopicRuns(props: { runs: Run[]; checkIns: Message[]; dotName: string }) {
  const { runs, dotName } = props;
  const qc = useQueryClient();
  const events = useQueries({ queries: runs.map((run) => eventsQuery(qc, run.id)) });
  const approvals = useQueries({
    queries: runs.map((run) => ({
      queryKey: keys.approvals(run.id),
      queryFn: () => commands.approvalsForRun(run.id),
    })),
  });
  const eventsByRun = new Map<string, RunEventRecord[]>(
    runs.map((run, i) => [run.id, events[i]?.data ?? []]),
  );
  const asked = approvals.flatMap((q) => q.data ?? []);
  const pending = asked.filter((a) => a.status === "pending");
  const latest = runs.at(-1);
  // Why the last run failed stands below its transcript, so the transcript does not repeat it.
  const failure = latest?.status === "failed" ? latest.error : null;
  const checkIns = props.checkIns.filter((m) => runs.some((run) => run.id === m.run_id));
  return (
    <div className="flex flex-col gap-4">
      <Transcript runs={runs} events={eventsByRun} shownError={failure} messages={checkIns} />
      <LoadErrors queries={[...events, ...approvals]} />
      <AppliedCalls approvals={asked} />
      {pending.map((approval) => (
        <ApprovalCard key={approval.id} approval={approval} dotName={dotName} />
      ))}
      {failure && (
        <p role="alert" className="rounded-md border border-destructive/50 p-2 text-destructive">
          {failure}
        </p>
      )}
    </div>
  );
}
```

```tsx
import { Send } from "lucide-react";
import { useEffect, useRef, useState } from "react";

import { Button } from "@/components/ui/button";
import { Textarea } from "@/components/ui/textarea";

/// Where a message is typed. Enter sends; Shift+Enter starts a new line. The text is cleared
/// once the send has succeeded; a refused message stays for another try.
export function Composer(props: {
  disabled: boolean;
  hint: string;
  onSend: (message: string) => Promise<unknown>;
}) {
  const [text, setText] = useState("");
  const box = useRef<HTMLTextAreaElement>(null);
  // The box is disabled while a send is on its way and while the dot works, and a browser
  // takes the focus from a disabled control. When the box can be used again it gets the focus
  // back, unless the user has put it somewhere else in the meantime.
  const wasDisabled = useRef(props.disabled);
  useEffect(() => {
    const freed = wasDisabled.current && !props.disabled;
    wasDisabled.current = props.disabled;
    const focused = document.activeElement;
    if (freed && (focused === null || focused === document.body || focused === box.current)) {
      box.current?.focus();
    }
  }, [props.disabled]);
  function send() {
    const message = text.trim();
    if (message === "" || props.disabled) return;
    // The mutation's onError reports a failure; here it only keeps the text.
    props.onSend(message).then(
      () => setText(""),
      () => {},
    );
  }
  return (
    <div className="flex items-end gap-2 px-3 pb-3">
      <label htmlFor="chat-message" className="sr-only">
        Message
      </label>
      <Textarea
        id="chat-message"
        ref={box}
        rows={2}
        placeholder={props.hint}
        disabled={props.disabled}
        value={text}
        onChange={(e) => setText(e.target.value)}
        onKeyDown={(e) => {
          if (e.key === "Enter" && !e.shiftKey) {
            e.preventDefault();
            send();
          }
        }}
      />
      <Button disabled={props.disabled || text.trim() === ""} onClick={send}>
        <Send aria-hidden /> Send
      </Button>
    </div>
  );
}
```

```tsx
/// The topic `pick` names among `shown`; undefined for a new topic. A chosen topic that is no

export function replyTarget(pick: ReplyPick, shown: Topic[]): Topic | undefined {
  if (pick.kind === "new") return undefined;
  const chosen = pick.kind === "topic" ? shown.find((t) => t.rootId === pick.rootId) : undefined;

  const target = replyTarget(pick, shown);
  const busy = target?.runs.some(isActive) ?? false;
  const approving = target?.runs.some((run) => run.status === "awaiting_approval") ?? false;
  // A reply resumes the last run's session. A run that ended before its engine had one (a
  // failed start, a cancel while queued) leaves nothing to resume: the core refuses it.
  const closed = target !== undefined && !busy && lastRun(target).session_id === null;
  const runIds = new Set(shown.flatMap((topic) => topic.runs.map((run) => run.id)));
  const open = props.checkIns.filter(
    (m) => m.run_id !== null && runIds.has(m.run_id) && isOpenQuestion(m),
  );
  const question = open.at(-1);
  const questionBusy =
    question !== undefined &&
    shown.some((t) => t.runs.some((r) => r.id === question.run_id) && t.runs.some(isActive));
  // "Reply to question" pressed: the composer sends the answer to the open question.
  const [replying, setReplying] = useState(false);
  const answering = replying && question !== undefined;
  // What a send waits for before it is done: the dot's runs and the threads, loaded again. Until
  // then the screen still ends at the old run, and a second message would continue from it.
  const reload = () =>
    Promise.all([
      qc.invalidateQueries({ queryKey: ["runs"] }),
      qc.invalidateQueries({ queryKey: ["thread"] }),
    ]);
  // An answer or a message that went to another topic than the older one shown is seen in the
  // conversation.
  const follow = (rootId: string) => {
    if (olderRoot !== undefined && rootId !== olderRoot) void navigate(`/home/${dotId}`);
  };
  const send = useMutation({
    mutationFn: (message: string) =>
      commands.chat(dotId, message, target ? lastRun(target).id : null),
    onSuccess: (run) => {
      onPick({ kind: "default" });
      follow(run.root_run_id);
      return reload();
    },
    // The core refuses a message when the topic it holds is ahead of this one. So the topics
    // are loaded again after any refusal, and the composer follows what they bring.
    onError: (error) => {
      notifyError(error);
      return reload();
    },
  });
  const answer = useMutation({
    mutationFn: (text: string) => commands.messageReply(question!.id, text),
    onSuccess: (run) => {
      setReplying(false);
      invalidate(qc, ["messages"]);
      follow(run.root_run_id);
      return reload();
    },
    onError: (error) => {
      notifyError(error);
      invalidate(qc, ["messages"]);
      return reload();
    },
  });
  // Opening the conversation marks its open questions read; they stay open until answered.
  const unread = open
    .filter((m) => m.read_at === null)
    .map((m) => m.id)
    .join(" ");
  useEffect(() => {
    if (unread === "") return;
    for (const id of unread.split(" ")) {
      void commands.messageMarkRead(id).then(
        () => invalidate(qc, ["messages"]),
        () => {},
      );
    }
  }, [unread, qc]);

  const chip =
    target === undefined
      ? "New topic"
      : olderRoot === undefined && target.kind === "chat"
        ? "Replying to: current topic"
        : `Replying to: ${topicTitle(target)}`;
  const hint = answering
    ? "Your answer to the question"
    : busy
      ? approving
        ? "Waiting for your approval above"
        : `${dotName} is working on this…`
      : closed
        ? "This topic cannot be continued"
        : `Message ${dotName}…`;
  return (
    <div className="flex flex-col gap-2 border-t pt-2">
      {closed && (
        <p className="flex items-center gap-2 px-3 text-muted-foreground">
          <span className="flex-1">
            This topic cannot be continued: its last run ended before the dot had a session to
            resume.
          </span>
          <Button size="sm" variant="outline" onClick={() => onPick({ kind: "new" })}>
            New topic
          </Button>
        </p>
      )}
      {question && (
        <div
          role="region"
          aria-label="Open question"
          className="flex flex-wrap items-center gap-2 px-3"
        >
          <p className="min-w-0 flex-1 whitespace-pre-wrap">
            {dotName} asked: {question.text}
          </p>
          {question.choices?.map((choice) => (
            <Button
              key={choice}
              size="sm"
              variant="outline"
              disabled={questionBusy || answer.isPending}
              onClick={onSingleClick(() => answer.mutate(choice))}
            >
              {choice}
            </Button>
          ))}
          <Button
            size="sm"
            variant={answering ? "default" : "outline"}
            aria-pressed={answering}
            disabled={questionBusy}
            onClick={() => setReplying(!replying)}
          >
            Reply to question
          </Button>
        </div>
      )}
      <div
        role="group"
        aria-label="Reply target"
        className="flex items-center gap-1 px-3 text-xs text-muted-foreground"
      >
        <span>{chip}</span>
        {pick.kind !== "default" && (
          <Button
            size="icon-xs"
            variant="ghost"
            aria-label="Clear the reply target"
            title="Clear the reply target"
            onClick={() => onPick({ kind: "default" })}
          >
            <X aria-hidden />
          </Button>
        )}
      </div>
      <Composer
        disabled={
          answering ? questionBusy || answer.isPending : busy || send.isPending || closed
        }
        hint={hint}
        onSend={(message) =>
          answering ? answer.mutateAsync(message) : send.mutateAsync(message)
        }
      />
    </div>
  );
}
```

```tsx
/// `/chat/:dotId/:runId` the topic of that run, in the conversation when it is there, else
/// alone. A run that cannot be found opens the dot's conversation.
export function ChatRedirect() {
  const { dotId, runId } = useParams();
  const thread = useQuery({
    queryKey: keys.thread(runId ?? ""),
    queryFn: () => commands.runThread(runId!),
    enabled: runId !== undefined,
  });
  const list = useQuery({
    queryKey: [...keys.runs(dotId!), "home"],
    queryFn: () => commands.listRuns(dotId!, LOADED_RUNS),
    enabled: runId !== undefined,
  });
  const home = `/home/${dotId}`;
  if (runId === undefined || thread.isError || list.isError) return <Navigate to={home} replace />;
  if (thread.isPending || list.isPending) return null;
  const root = thread.data[0]?.root_run_id ?? runId;
  const shown = conversation(topicsOf(list.data)).some((topic) => topic.rootId === root);
  return <Navigate to={shown ? home : `${home}/${root}`} replace />;
}
```
