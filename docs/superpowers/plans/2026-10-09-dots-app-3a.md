# Dots — Plan 3a: Core Additions and Tauri Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the Dots core everything the desktop UI needs (settings, status, review actions, a degraded start, the Plan 2 policy follow-ups) and wrap it in a Tauri 2 shell with the full command and event surface, tray, notifications and autostart.

**Architecture:** `dots-core` gains a `settings` module and table access, `Runtime` read and review methods, `Runtime::status`, a server-less start when the port is taken, and schedule pausing. `apps/dots-app` is a thin Tauri 2 adapter: every command is a one-line wrapper over `Runtime` that takes ids (never paths), one forwarder task re-emits each `RuntimeEvent` to the webview and drives OS notifications and the tray's Inbox count, and the tray offers Open, Inbox (n), Pause all schedules and Quit. `ui/` is a Vite + React + TypeScript app; in this plan it holds only the typed API layer (zod schemas, command wrappers, event listeners), a contract test against Rust-written samples, and a placeholder page. The screens are Plan 3b.

**Tech Stack:** Rust 1.95 (edition 2021), tokio, sqlx 0.8 (SQLite), Tauri 2.12 with tauri-plugin-single-instance 2.5, -autostart 2.7, -notification 2.5, -opener 2.7, -dialog 2.8, tracing-appender 0.2; Bun 1.3, Vite 8.3, React 19.3, TypeScript 6.0, zod 4.6, Vitest 5.0.

**Spec:** `docs/superpowers/specs/2026-10-08-dots-design.md` — §12 "Plan 3 decisions" (pinned 2026-10-09 in commit `f5afab1`), §3 settings and `runs.reviewed_at`, §4 version check, §5 path rules and `shell` stdin, §7 UI, §8 rows "Port in use" and "Runtime fails to start".

**Plan 3 is split in three.** This is **3a** (core additions, Tauri shell, command and event surface). **3b** builds the six screens on this plan's API layer. **3c** adds the Windows Job Object, the full manual smoke and the NSIS installer.

**Previous plans:** `docs/superpowers/plans/2026-10-08-dots-core.md` (Plan 1), `docs/superpowers/plans/2026-10-09-dots-local-engine.md` (Plan 2, merged in PR #1).

## Review Focus

1. **A discard that deletes the wrong folder** — a run row whose `workspace_path` points outside `%LOCALAPPDATA%\dots\worktrees` (tampering, an old layout), a folder-mode run, or a thread that is still running — must be refused and must never remove the user's checkout. → Task 7 `discard_refuses_paths_outside_the_worktrees_folder`, `folder_runs_have_no_worktree_to_diff_or_discard`, `discard_waits_for_the_thread_to_finish`.
2. **Dots started while port 47321 is taken** (a second copy, another app) must still open, report the problem, keep local dots and schedules running, and fail Claude runs with an actionable message instead of hanging on a missing MCP endpoint. → Task 5 `a_taken_port_starts_without_the_server_and_fails_claude_runs`.
3. **A deny rule worked around by its directory form, an absolute pattern, or a search from the root** — `Read(secret/**)` vs `LS secret`, `Read(C:/repo/keys/**)` vs a workspace-relative `keys/id_rsa`, `grep` from `.` reading `secret/` — must stay denied for local dots. → Task 1 `a_dir_glob_deny_also_covers_the_directory_itself`, `absolute_deny_patterns_match_workspace_relative_inputs`; Task 2 `walking_tools_leave_out_what_the_policy_denies`, `searches_skip_paths_the_dot_policy_denies`.
4. **A settings table with a bad or unknown row** (hand edit, an older or newer version) must not keep Dots from starting, and a start that really fails must show its reason instead of a blank window. → Task 4 `bad_and_unknown_rows_are_ignored_one_by_one`; Task 8 `a_data_dir_that_cannot_be_created_is_a_startup_error`, `a_failed_start_answers_every_command_with_an_internal_error`.
5. **Notification noise** — chat runs, "Mark reviewed" re-publishing old runs, a parked run closed after its decision — must not pop notifications; every scheduled or webhook run that ends or parks must notify exactly once. → Task 10 `a_run_notifies_once_when_it_ends_or_parks`, `chat_runs_and_runs_first_seen_finished_stay_quiet`.

### Task 2: Walking tools skip what the policy denies

A `grep` or `glob` from the workspace root used to read every file below it, including a subtree the dot's policy denies. The local engine now hands the walking tools a `PathFilter` built from the dot's policy; an entry denied for the walking tool or for `Read` is left out (a denied directory is not entered), and the output says how many entries were hidden.

```rust
/// Runs `name` with the walking tools filtered by `policy`, as the local engine does.
async fn run_filtered(ws: &Path, policy: &Policy, name: &str, args: Value) -> ToolOutput {
    let call = tools::prepare(name, &args, ws).unwrap_or_else(|e| panic!("prepare: {e}"));
    let filter = tools::PathFilter::from_policy(policy, call.alias, ws);
    tools::run_with(&call, ws, &CancellationToken::new(), &filter).await
}
```

```rust
/// Decides which entries the walking tools (`list_dir`, `glob`, `grep`) leave out, given each
/// entry's workspace-relative path. The default hides nothing.
#[derive(Clone, Default)]
pub struct PathFilter(Option<Arc<HideFn>>);

type HideFn = dyn Fn(&str) -> bool + Send + Sync;

impl PathFilter {
    pub fn new(hides: impl Fn(&str) -> bool + Send + Sync + 'static) -> Self {
        Self(Some(Arc::new(hides)))
    }

    /// Hides the entries `policy` denies for the walking tool `alias` or for `Read`, so a
    /// search from the workspace root never reads a denied subtree.
    pub fn from_policy(policy: &Policy, alias: &'static str, workspace: &Path) -> Self {
        let (policy, workspace) = (policy.clone(), workspace.to_path_buf());
        Self::new(move |rel| {
            let ws = Some(workspace.as_path());
            policy.resolve_in(alias, &json!({ "path": rel }), ws) == Action::Deny
                || policy.resolve_in("Read", &json!({ "file_path": rel }), ws) == Action::Deny

        self.0.as_ref().is_some_and(|f| f(rel))
```

```rust
pub(super) async fn read_file(root: &Path, input: &Value) -> ToolOutput {

        Ok(p) => p,
        Err(e) => return ToolOutput::err(e),
```

```rust
/// Walks `base`, honouring `.gitignore` files and skipping `.git` and the entries `filter`
/// hides; a hidden directory is not entered. Hidden entries are counted in `hidden`.
fn walk(
    root: &Path,
    base: &Path,
    filter: &PathFilter,
    hidden: &Arc<AtomicUsize>,
) -> impl Iterator<Item = PathBuf> {
    let (root, filter, hidden) = (root.to_path_buf(), filter.clone(), hidden.clone());
    ignore::WalkBuilder::new(base)
        .hidden(false)
        .require_git(false)
        .sort_by_file_path(|a, b| a.cmp(b))
        .filter_entry(move |e| {
            if e.file_name() == ".git" {
                return false;
            }
            // Depth 0 is `base` itself, which the permission gate already judged.
            if e.depth() > 0 && filter.hides(&display(&root, e.path())) {
                hidden.fetch_add(1, Ordering::Relaxed);
                return false;
            }
            true
        })
        .build()
        .filter_map(|e| e.ok())
        .filter(|e| e.file_type().is_some_and(|t| t.is_file()))
        .map(|e| e.into_path())
}
```

```rust
/// shared so that what was read survives when the reader is abandoned before EOF.
async fn pump(mut r: impl AsyncRead + Unpin, tail: Tail) {
    let mut chunk = [0u8; 4096];
    while let Ok(n @ 1..) = r.read(&mut chunk).await {
        let mut buf = tail.lock().unwrap();
        buf.extend_from_slice(&chunk[..n]);
        let excess = buf.len().saturating_sub(2 * MAX_OUTPUT);
        buf.drain(..excess);
    }
}

fn take(tail: &Tail) -> String {
    String::from_utf8_lossy(&std::mem::take(&mut *tail.lock().unwrap())).into_owned()
}

/// Appends `more` to `text` on a new line, unless `more` is blank.
fn append_line(text: &mut String, more: &str) {
    if more.trim().is_empty() {
        return;
    }
    if !text.is_empty() && !text.ends_with('\n') {
        text.push('\n');
    }
    text.push_str(more);
}

enum End {
    Exited(Option<i32>),
    TimedOut,
    Cancelled,
}

pub(super) async fn shell(root: &Path, input: &Value, cancel: &CancellationToken) -> ToolOutput {
    let script = str_arg(input, "command");
    let secs = input
        .get("timeout")
        .and_then(Value::as_u64)
        .unwrap_or(DEFAULT_TIMEOUT_SECS)
        .clamp(1, MAX_TIMEOUT_SECS);
    let (mut cmd, stdin) = command_for(script);
    cmd.current_dir(root)
        .stdin(if stdin.is_some() {
            Stdio::piped()
        } else {
            Stdio::null()
        })
        .stdout(Stdio::piped())
        .stderr(Stdio::piped())
        .kill_on_drop(true);
    crate::proc::hide_window(&mut cmd);
    let mut child = match cmd.spawn() {
        Ok(c) => c,
        Err(e) => return ToolOutput::err(format!("failed to start the shell: {e}")),
    };
    let pid = child.id();
    if let (Some(bytes), Some(mut pipe)) = (stdin, child.stdin.take()) {
        // Written from a task so a large script never blocks reading the output; dropping the
        // pipe closes it, which ends the bootstrap's read.
        tokio::spawn(async move {
            let _ = pipe.write_all(&bytes).await;
        });
    }
    let (out, err) = (Tail::default(), Tail::default());
    let mut readers = [
        tokio::spawn(pump(
            child.stdout.take().expect("stdout is piped"),
            out.clone(),
        )),
        tokio::spawn(pump(
            child.stderr.take().expect("stderr is piped"),
            err.clone(),
        )),
    ];

    let end = tokio::select! {
        s = child.wait() => End::Exited(s.ok().and_then(|s| s.code())),
        _ = tokio::time::sleep(Duration::from_secs(secs)) => End::TimedOut,
        _ = cancel.cancelled() => End::Cancelled,
    };
    if !matches!(end, End::Exited(_)) {
        if let Some(pid) = pid {
            stop(pid).await;
        }
        let _ = child.start_kill();
        let _ = child.wait().await;
    }
    // A background process the shell started may hold the pipes open; wait 5 s at most in all,
    // then keep what was read.
    let _ = tokio::time::timeout(Duration::from_secs(5), async {
        for r in &mut readers {
            let _ = r.await;
        }
    })
    .await;
    let held = readers.iter().any(|r| !r.is_finished());
    for r in &readers {
        r.abort();
    }
    let mut text = take(&out);
    append_line(&mut text, &take(&err));
    if held {
        append_line(&mut text, HELD_OPEN);
    }
    let text = cap_tail(text);
    match end {
        End::Exited(Some(0)) if text.trim().is_empty() => ToolOutput::ok("(no output)"),
        End::Exited(Some(0)) => ToolOutput::ok(text),
        End::Exited(code) => ToolOutput::err(format!(
            "exit code {}\n{text}",
            code.map_or_else(|| "unknown".to_string(), |c| c.to_string())
        )),
        End::TimedOut => {
            ToolOutput::err(format!("timed out after {secs}s and was stopped\n{text}"))
        }
        End::Cancelled => ToolOutput::err("cancelled"),
    }
}
```

```rust
use serde_json::Value;

use super::Store;
use crate::settings::Settings;
use crate::Result;

impl Store {
    /// The stored settings, with defaults for missing keys. Unknown keys are ignored, and so is
    /// a stored value that does not fit its field (logged), so one bad row never hides the rest.
    pub async fn get_settings(&self) -> Result<Settings> {
        let rows: Vec<(String, String)> = sqlx::query_as("SELECT key, value FROM settings")
            .fetch_all(&self.pool)
            .await?;
        let mut merged = serde_json::to_value(Settings::default())?;
        for (key, raw) in rows {
            if merged.get(&key).is_none() {
                continue;
            }
            let mut candidate = merged.clone();
            match serde_json::from_str::<Value>(&raw) {
                Ok(value) => candidate[&key] = value,
                Err(e) => {
                    tracing::warn!("ignoring setting {key}: {e}");
                    continue;
                }
            }
            match serde_json::from_value::<Settings>(candidate.clone()) {
                Ok(_) => merged = candidate,
                Err(e) => tracing::warn!("ignoring setting {key}: {e}"),
            }
        }
        Ok(serde_json::from_value(merged)?)
    }

    /// Validates `settings` and stores every field in one transaction.
    pub async fn put_settings(&self, settings: &Settings) -> Result<()> {
        settings.validate()?;
        let Value::Object(fields) = serde_json::to_value(settings)? else {
            unreachable!("Settings serializes to a JSON object");
        };
        let mut tx = self.pool.begin().await?;
        for (key, value) in fields {
            sqlx::query(
                "INSERT INTO settings (key, value) VALUES (?, ?) \
                 ON CONFLICT(key) DO UPDATE SET value = excluded.value",
            )
            .bind(&key)
            .bind(value.to_string())
            .execute(&mut *tx)
            .await?;
        }
        tx.commit().await?;
        Ok(())
    }
}
```

```rust
#[tokio::test]
async fn a_taken_port_starts_without_the_server_and_fails_claude_runs() {
    let dir = tempfile::tempdir().unwrap();
    let holder = std::net::TcpListener::bind("127.0.0.1:0").unwrap();
    let taken = holder.local_addr().unwrap().port();
    let mut cfg = config(&dir);
    cfg.port = taken;
    let rt = Runtime::start(cfg).await.unwrap();

    let status = rt.status().await;
    assert_eq!(status.port, taken);
    let err = status.server_error.expect("server error reported");
    assert!(err.contains(&taken.to_string()), "{err}");

    let dot = rt.create_dot(folder_spec(&dir, "cli")).await.unwrap();
    let run = rt.run_now(&dot.id).await.unwrap();
    let failed = wait_status(rt.store(), &run.id, RunStatus::Failed, 15).await;
    assert_eq!(
        failed.error,
        Some(format!(
            "local server is not running: port {taken} is in use. Change the port in Settings \
             and restart Dots."
        ))
    );

    // Local dots do not need the server.
    let llm = Llm::start(vec![text("done locally")]).await;
    let mut s = folder_spec(&dir, "loco");
    s.engine = EngineKind::Local;
    s.endpoint_url = Some(llm.endpoint());
    s.model = "m".into();
    let local = rt.create_dot(s).await.unwrap();
    let run = rt.run_now(&local.id).await.unwrap();
    let done = wait_status(rt.store(), &run.id, RunStatus::Succeeded, 15).await;
    assert_eq!(done.summary.as_deref(), Some("done locally"));
    rt.shutdown();
}
```

```rust
    pub async fn chat(
        &self,
        dot_id: &str,
        message: &str,
        parent_run_id: Option<&str>,
    ) -> Result<Run> {
        if message.trim().is_empty() {
            return Err(Error::Invalid("message must not be empty".into()));
        }
        self.store.get_dot(dot_id).await?;
        let mut new = NewRun::new(dot_id, TriggerKind::Chat);
        new.payload = Some(json!({ "message": message }));
        if let Some(pid) = parent_run_id {
            let parent = self.store.get_run(pid).await?;
            if !parent.status.is_terminal() || parent.session_id.is_none() {
                return Err(Error::Conflict(
                    "parent run has no finished session to continue".into(),
                ));
            }
            if parent.dot_id != dot_id {
                return Err(Error::Invalid(format!(
                    "run {pid} belongs to a different dot"
                )));

            new.parent_run_id = Some(parent.id.clone());
            new.root_run_id = Some(parent.root_run_id.clone());
            new.session_id = parent.session_id.clone();
            new.workspace_path = parent.workspace_path.clone();
            new.branch = parent.branch.clone();
            new.base_commit = parent.base_commit.clone();

            }
        }
```
```rust
    }

/// Total patch text a diff returns; later files are listed without their patch.
pub const MAX_DIFF_BYTES: usize = 1024 * 1024;
/// Files with a NUL byte in their first 8000 bytes are treated as binary (as git does).
const BINARY_PROBE: usize = 8000;

/// Splits `git diff` output into one entry per file.
pub fn parse_diff(text: &str) -> Vec<FileDiff> {
    let mut files: Vec<FileDiff> = Vec::new();
    for line in text.split_inclusive('\n') {
        if let Some(header) = line.strip_prefix("diff --git ") {
            let header = header.trim_end();
            let path = header
                .rsplit_once(" b/")
                .map_or(header, |(_, b)| b)
                .to_string();
            files.push(FileDiff {
                path,
                status: FileStatus::Modified,
                patch: String::new(),
                binary: false,
            });
        }
        let Some(file) = files.last_mut() else {
            continue;
        };
        file.patch.push_str(line);
        let line = line.trim_end_matches(['\r', '\n']);
        if line.starts_with("new file mode") {
            file.status = FileStatus::Added;
        } else if line.starts_with("deleted file mode") {
            file.status = FileStatus::Deleted;
        } else if let Some(to) = line.strip_prefix("rename to ") {
            file.status = FileStatus::Renamed;
            file.path = to.to_string();
        } else if line.starts_with("Binary files ") {
            file.binary = true;
        } else if let Some(p) = line.strip_prefix("+++ b/") {
            file.path = p.to_string();
        }
    }
    for f in files.iter_mut().filter(|f| f.binary) {
        f.patch.clear();
    }
    files
}

/// A new-file patch for an untracked file; `None` when it is binary.
fn untracked_patch(rel: &str, bytes: &[u8]) -> Option<String> {
    if bytes.iter().take(BINARY_PROBE).any(|b| *b == 0) {
        return None;
    }
    let text = String::from_utf8_lossy(bytes);
    let mut patch =
        format!("diff --git a/{rel} b/{rel}\nnew file mode 100644\n--- /dev/null\n+++ b/{rel}\n");
    let lines: Vec<&str> = text.lines().collect();
    if !lines.is_empty() {
        patch.push_str(&format!("@@ -0,0 +1,{} @@\n", lines.len()));
        for l in &lines {
            patch.push('+');
            patch.push_str(l);
            patch.push('\n');
        }
        if !text.ends_with('\n') {
            patch.push_str("\\ No newline at end of file");
        }
    }
    Some(patch)
}

/// The changes of the worktree at `path` against `base_commit`: committed and uncommitted
/// changes to tracked files, then untracked files (not ignored) as additions. Patch text is
/// capped at `MAX_DIFF_BYTES`; files past the cap are listed with an empty patch.
pub async fn diff(path: &Path, base_commit: &str) -> Result<WorktreeDiff> {
    let tracked = git(

            "core.quotePath=false",
            "diff",
            "--no-color",
            "--no-ext-diff",
            "--no-textconv",
            "--find-renames",
            base_commit,
            "--",
        ],
    )
    .await?;
    let mut files = parse_diff(&tracked);
    let listed = git(
        path,
        &[
            "-c",
            "core.quotePath=false",
            "ls-files",
            "--others",
            "--exclude-standard",
            "-z",
        ],
    )
    .await?;
    let mut untracked: Vec<&str> = listed.split('\0').filter(|p| !p.is_empty()).collect();
    untracked.sort();
    let mut truncated = false;
    for rel in untracked {
        let full = path.join(rel);
        let size = std::fs::metadata(&full).map_or(0, |m| m.len());
        let (patch, binary) = if size > MAX_DIFF_BYTES as u64 {
            truncated = true;
            (String::new(), false)
        } else {
            match tokio::fs::read(&full).await {
                Ok(bytes) => match untracked_patch(rel, &bytes) {
                    Some(p) => (p, false),
                    None => (String::new(), true),
                },
                Err(_) => (String::new(), false),
            }
        };
        files.push(FileDiff {
            path: rel.to_string(),
            status: FileStatus::Added,
            patch,
            binary,
        });
    }
    files.sort_by(|a, b| a.path.cmp(&b.path));
    let mut used = 0;
    for f in &mut files {
        if used + f.patch.len() > MAX_DIFF_BYTES {
            f.patch.clear();
            truncated = true;
        }
        used += f.patch.len();
    }
    Ok(WorktreeDiff { files, truncated })
}
```

```rust
        None => local_data.join("dots"),
    }

    data_dir.join("logs")
}

pub fn start_hidden(mut args: impl Iterator<Item = String>) -> bool {

}

/// Daily log files in `log_dir`, the last seven kept. `None` if logging could not start;
/// the app runs without a log then. Keep the guard alive for the whole run.
pub fn init_logging(log_dir: &Path) -> Option<WorkerGuard> {
    let appender = Builder::new()
        .rotation(Rotation::DAILY)
        .filename_prefix("dots")
        .filename_suffix("log")
        .max_log_files(LOG_FILES_KEPT)
        .build(log_dir)
        .ok()?;
    let (writer, guard) = tracing_appender::non_blocking(appender);
    tracing_subscriber::fmt()
        .with_writer(writer)
        .with_ansi(false)
        .with_env_filter(EnvFilter::try_from_default_env().unwrap_or_else(|_| "info".into()))
        .try_init()
        .ok()?;
    Some(guard)
}
```

```rust
/// Keeps the log writer flushing until the app exits.

/// Shows and focuses the main window.
pub fn show_main(app: &AppHandle) {
    if let Some(w) = app.get_webview_window("main") {
        let _ = w.unminimize();
        let _ = w.show();
        let _ = w.set_focus();
    }

fn setup(app: &AppHandle) -> Result<(), Box<dyn std::error::Error>> {
    let data_dir = startup::data_dir(
        &app.path().local_data_dir()?,
        std::env::var_os(startup::DATA_DIR_ENV),
    );
    let log_dir = startup::log_dir(&data_dir);
    if let Some(guard) = startup::init_logging(&log_dir) {
        app.manage(LogGuard(guard));
    }
    tracing::info!("starting Dots {}", env!("CARGO_PKG_VERSION"));
    let runtime = tauri::async_runtime::block_on(startup::start_runtime(&data_dir));
    let failed = runtime.is_err();
    if let Err(e) = &runtime {
        tracing::error!("{e}");
    }
    app.manage(AppState::new(runtime.map(|(rt, _)| rt), log_dir));
    // A failed start always shows its error page, even when launched hidden.
    if failed || !startup::start_hidden(std::env::args()) {
        show_main(app);
    }
    Ok(())
}

    let app = tauri::Builder::default()
        // Must be registered first: a second launch only focuses the running app.
        .plugin(tauri_plugin_single_instance::init(|app, _args, _cwd| {
            show_main(app)
        }))
        .plugin(tauri_plugin_dialog::init())
        .plugin(tauri_plugin_opener::init())
        .setup(|app| {
            setup(app.handle())?;
            Ok(())
        })
        .on_window_event(|window, event| {
            // Closing the window keeps Dots running in the tray.
            if let WindowEvent::CloseRequested { api, .. } = event {
                api.prevent_close();
                let _ = window.hide();
            }
```

```rust
//! Forwards `RuntimeEvent`s to the webview.

use std::sync::Arc;

use dots_core::events::RuntimeEvent;
use dots_core::Runtime;
use tauri::{AppHandle, Emitter};
use tokio::sync::broadcast::error::RecvError;

/// Every `RuntimeEvent`, as the same JSON (`{"type": "run_updated", ...}`).
pub const RUNTIME_EVENT: &str = "runtime";
/// Events were dropped (the webview fell behind); the UI refetches everything.
pub const LAGGED_EVENT: &str = "runtime-lagged";

pub fn spawn_forwarder(app: AppHandle, rt: Arc<Runtime>) {
    let mut rx = rt.subscribe();
    tauri::async_runtime::spawn(async move {
        loop {
            match rx.recv().await {
                Ok(ev) => forward(&app, &ev),
                Err(RecvError::Lagged(n)) => {
                    tracing::warn!("UI event forwarder skipped {n} events");
                    let _ = app.emit(LAGGED_EVENT, ());
                }
                Err(RecvError::Closed) => break,
            }
        }
    });
}

fn forward(app: &AppHandle, ev: &RuntimeEvent) {
    if let Err(e) = app.emit(RUNTIME_EVENT, ev) {
        tracing::warn!("emitting a runtime event failed: {e}");
    }
}
```

```rust
//! tray's Inbox count current.

use std::collections::HashMap;
use std::sync::Arc;

use dots_core::events::RuntimeEvent;
use dots_core::model::{Run, RunStatus, TriggerKind};
use dots_core::Runtime;
use tauri::{AppHandle, Emitter};

use tokio::sync::broadcast::error::RecvError;

use crate::tray;

/// Every `RuntimeEvent`, as the same JSON (`{"type": "run_updated", ...}`).
pub const RUNTIME_EVENT: &str = "runtime";
/// Events were dropped (the webview fell behind); the UI refetches everything.
pub const LAGGED_EVENT: &str = "runtime-lagged";
/// The tray asks the UI to show a route, e.g. `/inbox`.
pub const NAVIGATE_EVENT: &str = "navigate";
/// The status changed outside the UI (the tray paused schedules); payload is the `Status`.
pub const STATUS_EVENT: &str = "status";

/// Something worth an OS notification.
#[derive(Debug, Clone, PartialEq)]
pub enum Notice {
    ApprovalNeeded { run_id: String, tool: String },
    RunEnded { run: Box<Run> },
}

/// Decides which events notify: approval requests, and a run moving from queued or running
/// into succeeded, failed or awaiting approval. Chat runs never notify (the user is watching
/// them). A run first seen in a final state (e.g. marked reviewed) and a parked run closed by
/// a decision do not notify either.
#[derive(Default)]
pub struct Notifier {
    active: HashMap<String, RunStatus>,
}

impl Notifier {
    pub fn decide(&mut self, ev: &RuntimeEvent) -> Option<Notice> {
        match ev {
            RuntimeEvent::ApprovalRequested { approval } => Some(Notice::ApprovalNeeded {
                run_id: approval.run_id.clone(),
                tool: approval.tool.clone(),
            }),
            RuntimeEvent::RunUpdated { run } => {
                let prev = if run.status.is_terminal() {
                    self.active.remove(&run.id)
                } else {
                    self.active.insert(run.id.clone(), run.status)
                };
                let was_working = matches!(prev, Some(RunStatus::Queued | RunStatus::Running));
                let ended = matches!(
                    run.status,
                    RunStatus::Succeeded | RunStatus::Failed | RunStatus::AwaitingApproval
                );
                (was_working && ended && run.trigger != TriggerKind::Chat).then(|| {
                    Notice::RunEnded {
                        run: Box::new(run.clone()),
                    }
                })
            }
            _ => None,
        }
    }
}

/// First non-empty line of `text`, at most 200 characters.
fn first_line(text: Option<&str>, fallback: &str) -> String {
    let line = text
        .and_then(|t| t.lines().map(str::trim).find(|l| !l.is_empty()))
        .unwrap_or(fallback);
    if line.chars().count() > 200 {
        line.chars().take(199).collect::<String>() + "…"
    } else {
        line.to_string()
    }
}

/// (title, body) of the notification.
pub fn notice_text(notice: &Notice, dot_name: &str) -> (String, String) {
    match notice {
        Notice::ApprovalNeeded { tool, .. } => (
            format!("{dot_name} needs approval"),
            format!("{tool} is waiting in the Inbox."),
        ),
        Notice::RunEnded { run } => match run.status {
            RunStatus::Succeeded => (
                format!("{dot_name} finished"),
                first_line(run.summary.as_deref(), "The run succeeded."),
            ),
            RunStatus::Failed => (
                format!("{dot_name} failed"),
                first_line(run.error.as_deref(), "The run failed."),
            ),
            _ => (
                format!("{dot_name} is waiting for approval"),
                "Open the Inbox to decide.".to_string(),
            ),
        },
    }
}

/// Whether the Inbox count may have changed.
pub fn affects_inbox(ev: &RuntimeEvent) -> bool {
    !matches!(ev, RuntimeEvent::RunEvent { .. })
}

pub fn spawn_forwarder(app: AppHandle, rt: Arc<Runtime>) {
    let mut rx = rt.subscribe();
    tauri::async_runtime::spawn(async move {
        let mut notifier = Notifier::default();
        tray::refresh_count(&app, &rt).await;
        loop {
            match rx.recv().await {
                Ok(ev) => {
                    if let Err(e) = app.emit(RUNTIME_EVENT, &ev) {
                        tracing::warn!("emitting a runtime event failed: {e}");
                    }
                    if let Some(notice) = notifier.decide(&ev) {
                        notify(&app, &rt, &notice).await;
                    }
                    if affects_inbox(&ev) {
                        tray::refresh_count(&app, &rt).await;
                    }
                }
                Err(RecvError::Lagged(n)) => {
                    tracing::warn!("UI event forwarder skipped {n} events");
                    let _ = app.emit(LAGGED_EVENT, ());
                    tray::refresh_count(&app, &rt).await;
                }
                Err(RecvError::Closed) => break,
            }
        }
    });
}

async fn notify(app: &AppHandle, rt: &Runtime, notice: &Notice) {
    let run_id = match notice {
        Notice::ApprovalNeeded { run_id, .. } => run_id,
        Notice::RunEnded { run } => &run.id,
    };
    let name = match rt.get_run(run_id).await {
        Ok(run) => rt.get_dot(&run.dot_id).await.map(|d| d.spec.name).ok(),
        Err(_) => None,
    };
    let (title, body) = notice_text(notice, name.as_deref().unwrap_or("A dot"));
    if let Err(e) = app.notification().builder().title(title).body(body).show() {
        tracing::warn!("showing a notification failed: {e}");
    }
}
```

```rust
impl Tray {
    pub fn build(app: &AppHandle, paused: bool) -> tauri::Result<Tray> {
        let open = MenuItem::with_id(app, "open", "Open Dots", true, None::<&str>)?;
        let inbox = MenuItem::with_id(app, "inbox", inbox_label(0), true, None::<&str>)?;
        let pause = CheckMenuItem::with_id(
            app,
            "pause",
            "Pause all schedules",
            true,
            paused,
            None::<&str>,
        )?;
        let quit = MenuItem::with_id(app, "quit", "Quit Dots", true, None::<&str>)?;
        let separator = PredefinedMenuItem::separator(app)?;
        let menu = Menu::with_items(app, &[&open, &inbox, &pause, &separator, &quit])?;
        let mut builder = TrayIconBuilder::with_id("main")
            .tooltip(tooltip(0))
            .menu(&menu)
            .show_menu_on_left_click(false)
            .on_menu_event(|app, event| on_menu(app, event.id().as_ref()))
            .on_tray_icon_event(|tray, event| {
                if let TrayIconEvent::Click {
                    button: MouseButton::Left,
                    button_state: MouseButtonState::Up,
                    ..
                } = event
                {
                    crate::show_main(tray.app_handle());
                }
            });
        if let Some(icon) = app.default_window_icon() {
            builder = builder.icon(icon.clone());
        }
        let icon = builder.build(app)?;
        Ok(Tray { icon, inbox, pause })
    }

    pub fn set_count(&self, count: usize) {
        let _ = self.icon.set_tooltip(Some(tooltip(count)));
        let _ = self.inbox.set_text(inbox_label(count));
    }

    pub fn set_paused(&self, paused: bool) {
        let _ = self.pause.set_checked(paused);
    }
}

/// Recomputes the Inbox count shown by the tray.
pub async fn refresh_count(app: &AppHandle, rt: &Runtime) {
    match rt.inbox_count().await {
        Ok(n) => {
            if let Some(tray) = app.try_state::<Tray>() {
                tray.set_count(n);
            }
        }
        Err(e) => tracing::warn!("counting the inbox failed: {e}"),
    }
}

fn on_menu(app: &AppHandle, id: &str) {
    let rt: Option<Arc<Runtime>> = app.state::<AppState>().rt().ok();
    match id {
        "open" => crate::show_main(app),
        "inbox" => {
            crate::show_main(app);
            let _ = app.emit(NAVIGATE_EVENT, "/inbox");
        }
        "pause" => {
            let Some(rt) = rt else { return };
            let app = app.clone();
            tauri::async_runtime::spawn(async move {
                // Toggle from the runtime's state, not the menu's, so the two cannot disagree.
                let paused = !rt.status().await.schedules_paused;
                match rt.set_schedules_paused(paused).await {
                    Ok(status) => {
                        if let Some(tray) = app.try_state::<Tray>() {
                            tray.set_paused(status.schedules_paused);
                        }
                        let _ = app.emit(STATUS_EVENT, &status);
                    }
                    Err(e) => tracing::error!("pausing schedules failed: {e}"),
                }
            });
        }
        "quit" => {
            if let Some(rt) = rt {
                rt.shutdown();
            }
            app.exit(0);
        }
        _ => {}
    }
}
```

```rust
/// Registers or removes the login entry (which starts Dots with `--hidden`). Debug builds
/// leave it alone: the entry would point at a development binary.
pub fn apply(app: &AppHandle, enabled: bool) {
    if cfg!(debug_assertions) {
        tracing::info!("debug build: autostart left unchanged (wanted {enabled})");
        return;
    }
    let launcher = app.autolaunch();
    let result = if enabled {
        launcher.enable()
    } else {
        launcher.disable()
    };
    if let Err(e) = result {
        tracing::warn!("updating autostart failed: {e}");
    }
}
```
