# What Needs Me Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A person sees at a glance which dots need them and what is new: each dot of the column counts what is unread, the dots that need them come first, the Home link shows the total, the tray lists the dots waiting, a notification says what it is about and a click on it opens that conversation, and nothing pops up for the dot being read.
**Architecture:** The core keeps `dots.seen_at` (migration 0010) and counts per dot what needs the person (open questions, pending approvals) and what is new since `seen_at` (runs that ended, notes); `dot_overview` carries `needs_you` and `unread`, `unread_total` sums them, `mark_dot_seen` publishes `dot_seen`, and the dot being viewed lives in memory with a watcher on the event bus that keeps it seen. The app wraps three commands, rewords the notifier, keeps it quiet for the viewed dot, gives each notification an id whose route `notify_routes.rs` keeps (the last 100) for one click handler registered at start, and adds a Needs you submenu to the tray. The UI shows a badge per row (`UnreadBadge`), sorts needs-you first, shows the total on the rail's Home link, refreshes on `dot_seen`, and tells the core what is viewed from a hook in `DotPane` (`use-viewing.ts`).
**Tech Stack:** Rust 1.97 (sqlx SQLite, tokio broadcast), Tauri 2.12.3 with tauri-plugin-notification 2.6.0 (`Notification::on_action`, `NotificationBuilder::id`) and its menu `Submenu`; React 19.3, @tanstack/react-query 5.104, zod 4.6, Vitest 5.0 with Testing Library and the fake backend (`ui/src/test/backend.ts`); Bun 1.4.3. No new dependency.
**Spec:** docs/superpowers/specs/2026-10-22-needs-you-design.md (sections 1 to 8; section 9 is out of scope)

## Review Focus

The inputs and failure modes the spec implies that are most likely to bite a person, each pinned to the test that covers it:

1. **The last word on what is viewed.** A switch from one dot to another sends "none" for the dot left and then the dot opened; the window losing the focus or being hidden; a conversation opening while the window is behind; an older topic of the dot. //! What needs the person (needs-you spec sections 2 and 3): each dot's open questions and
```rust
//! pending approvals, what is new since the person last looked at it, `mark_dot_seen`, and the
//! dot being viewed, which stays seen as its runs end and its notes arrive. Runs are stored but
//! never started (`max_concurrent_runs` is 0).

mod common;

use std::path::PathBuf;
use std::time::{Duration, Instant};

use common::spec;
use dots_core::checkins::Tool;
use dots_core::events::RuntimeEvent;
use dots_core::model::{Dot, MessageKind, NewRun, Run, RunStatus, TriggerKind};
use dots_core::store::Store;
use dots_core::{Config, Error, Runtime};
use serde_json::{json, Value};
use tempfile::TempDir;
use tokio::sync::broadcast::Receiver;

struct Rt {
    _dir: TempDir,
    rt: Runtime,
}

/// A runtime that stores runs and never starts one.
async fn start() -> Rt {
    let dir = tempfile::tempdir().unwrap();
    let mut cfg = Config::new(dir.path().join("data"));
    cfg.port = 0;
    cfg.claude_path = Some(PathBuf::from(env!("CARGO_BIN_EXE_fake-claude")));
    cfg.max_concurrent_runs = 0;
    let rt = Runtime::start(cfg).await.unwrap();
    Rt { _dir: dir, rt }
}

impl Rt {
    fn store(&self) -> &Store {
        self.rt.store()
    }

    async fn dot(&self, name: &str) -> Dot {
        self.rt.create_dot(spec(name)).await.unwrap()
    }

    /// A run of `dot` started by `trigger`, still queued.
    async fn queued(&self, dot: &Dot, trigger: TriggerKind) -> Run {
        self.store()
            .create_run(&NewRun::new(&dot.id, trigger))
            .await
            .unwrap()
    }

    /// A run of `dot` started by `trigger` that ended with `status`, stored without an event.
    async fn ended(&self, dot: &Dot, trigger: TriggerKind, status: RunStatus) -> Run {
        let run = self.queued(dot, trigger).await;
        self.store()
            .finish_run(&run.id, status, None, None)
            .await
            .unwrap()
    }

    /// The run's call of a check-in tool, which must be delivered.
    async fn checkin(&self, run: &Run, tool: Tool, input: Value) {
        let answer = self.rt.checkins().call(&run.id, tool, &input).await;
        assert!(answer.is_ok(), "{answer:?}");
    }

    /// The dot's `(needs_you, unread)` in the overview.
    async fn counts(&self, dot: &Dot) -> (u32, u32) {
        let rows = self.rt.dot_overview().await.unwrap();
        let row = rows.iter().find(|r| r.dot.id == dot.id).unwrap();
        (row.needs_you, row.unread)
    }

    /// Waits (at most 5 s) until the dot's counts are `want`.
    async fn counts_become(&self, dot: &Dot, want: (u32, u32)) {
        let deadline = Instant::now() + Duration::from_secs(5);
        loop {
            let counts = self.counts(dot).await;
            if counts == want {
                return;
            }
            assert!(
                Instant::now() < deadline,
                "counts {counts:?}, want {want:?}"
            );
            tokio::time::sleep(Duration::from_millis(20)).await;
        }
    }
}

/// Times are stored to the millisecond: what ends after a `mark_dot_seen` must end later.
async fn tick() {
    tokio::time::sleep(Duration::from_millis(5)).await;
}

/// Waits (at most 5 s) for the `DotSeen` of `dot_id`.
async fn seen(events: &mut Receiver<RuntimeEvent>, dot_id: &str) {
    let wait = async {
        loop {
            if let RuntimeEvent::DotSeen { dot_id: id } = events.recv().await.unwrap() {
                if id == dot_id {
                    return;
                }
            }
        }
    };
    tokio::time::timeout(Duration::from_secs(5), wait)
        .await
        .expect("a dot_seen event for the dot");
}

#[tokio::test]
async fn a_dot_counts_what_needs_the_person_and_what_is_new_since_it_was_seen() {
    let t = start().await;
    let dot = t.dot("worker").await;
    let other = t.dot("other").await;
    // Never seen: nothing that ended or was said is new, so an upgrade shows no wall of results.
    let old = t
        .ended(&dot, TriggerKind::Schedule, RunStatus::Succeeded)
        .await;
    t.checkin(&old, Tool::Notify, json!({"text": "Done before."}))
        .await;
    assert_eq!(t.rt.get_dot(&dot.id).await.unwrap().seen_at, None);
    assert_eq!(t.counts(&dot).await, (0, 0));

    // approval are closed.
    let asking = t
        .ended(&dot, TriggerKind::Manual, RunStatus::Succeeded)
        .await;
    t.checkin(&asking, Tool::Ask, json!({"question": "Ship it?"}))
        .await;
    let asked_before = t
        .ended(&dot, TriggerKind::Manual, RunStatus::Succeeded)
        .await;
    t.checkin(&asked_before, Tool::Ask, json!({"question": "Old?"}))
        .await;
    let old_question = t
        .store()
        .list_messages(Some(&dot.id))
        .await
        .unwrap()
        .into_iter()
```

```rust
/// What needs the person (needs-you spec section 3).
impl Runtime {
    /// The person looked at the dot's conversation: its `seen_at` is now, and `DotSeen` tells
    /// the app (the tray, the other windows). `NotFound` for an unknown dot.
    pub async fn mark_dot_seen(&self, dot_id: &str) -> Result<()> {
        mark_seen(&self.store, &self.bus, dot_id).await
    }

    /// The dot whose conversation is open in the focused window, or none. Held in memory, not
    /// stored; the last call wins. While a dot is viewed, a run of it that ends and a note it
    /// posts mark it seen.
    pub fn set_viewing(&self, dot_id: Option<&str>) {
        *lock(&self.viewing) = dot_id.map(str::to_string);
    }

    /// The dot being viewed (`set_viewing`).
    pub fn viewing(&self) -> Option<String> {
        lock(&self.viewing).clone()
    }

    /// The sum of every dot's `unread`: the count of the Home link (needs-you spec section 5).
    pub async fn unread_total(&self) -> Result<u32> {
        let mut total = 0;
        for dot in self.store.list_dots().await? {
            match self.store.dot_counts(&dot.id).await {
                Ok((_, unread)) => total += unread,
                Err(Error::NotFound(_)) => {}
                Err(e) => return Err(e),
            }
        }
        Ok(total)
    }
}

/// The dot being viewed (`Runtime::set_viewing`), shared with `watch_viewing`.
type Viewing = Arc<std::sync::Mutex<Option<String>>>;

fn lock(viewing: &Viewing) -> std::sync::MutexGuard<'_, Option<String>> {
    viewing
        .lock()
        .unwrap_or_else(std::sync::PoisonError::into_inner)
}

async fn mark_seen(store: &Store, bus: &Bus, dot_id: &str) -> Result<()> {
    store.mark_dot_seen(dot_id).await?;
    let _ = bus.send(RuntimeEvent::DotSeen {
        dot_id: dot_id.to_string(),
    });
    Ok(())
}

/// Marks the viewed dot seen when a run of it ends or it posts a note, so that what the person
/// is reading never counts as new. Missed events may have held such a change, so a lag marks
/// the viewed dot seen too.
fn watch_viewing(store: Store, bus: Bus, viewing: Viewing, shutdown: CancellationToken) {
    let mut events = bus.subscribe();
    tokio::spawn(async move {
        loop {
            let event = tokio::select! {
                _ = shutdown.cancelled() => break,
                event = events.recv() => event,
            };
            let dot_id = match event {
                Ok(RuntimeEvent::RunUpdated { run }) if run.status.is_terminal() => run.dot_id,
                Ok(RuntimeEvent::MessagePosted { message })
                    if message.kind == MessageKind::Note =>
                {
                    message.dot_id
                }
                Ok(_) => continue,
                Err(broadcast::error::RecvError::Lagged(_)) => match lock(&viewing).clone() {
                    Some(dot_id) => dot_id,
                    None => continue,
                },
                Err(broadcast::error::RecvError::Closed) => break,
            };
            let viewed = lock(&viewing).as_deref() == Some(dot_id.as_str());
            if viewed {
                if let Err(e) = mark_seen(&store, &bus, &dot_id).await {
                    tracing::warn!(dot = %dot_id, "marking the viewed dot seen failed: {e}");
                }
            }
        }
    });
}
```

```rust
/// A one-line preview of a call's input, as the UI's `toolPreview` shows it: its `command`,
/// `file_path`, `path`, `pattern` or `url` (the first line that is not blank), else the input
/// as compact JSON cut to 80 characters. `None` when there is nothing to show.
pub fn call_preview(input: &Value) -> Option<String> {
    if let Some(fields) = input.as_object() {
        for key in ["command", "file_path", "path", "pattern", "url"] {
            if let Some(Value::String(text)) = fields.get(key) {
                return text
                    .lines()
                    .map(str::trim)
                    .find(|l| !l.is_empty())
                    .map(str::to_string);
            }
        }
        if fields.is_empty() {
            return None;
        }
    }
    if input.is_null() {
        return None;
    }
    let text = input.to_string();
    Some(if text.chars().count() > 80 {
        text.chars().take(80).collect::<String>() + "…"
    } else {
        text
    })
}
```

```rust
//! notification clicked. Windows reports a click only while the toast is on screen: a click in
//! the Action Center opens Dots where it was.

use std::collections::VecDeque;
use std::sync::{Mutex, MutexGuard, PoisonError};

use tauri::{AppHandle, Emitter, Manager};
use tauri_plugin_notification::{ActionPerformed, NotificationExt};

use crate::events::NAVIGATE_EVENT;

/// How many notifications' routes are kept.
pub const KEPT: usize = 100;

/// The action the plugin reports for a click on the notification itself.
pub const TAP: &str = "tap";

/// The routes of the last `KEPT` notifications, by id, oldest first.
#[derive(Debug, Default)]
pub struct Routes {
    last: i32,
    kept: VecDeque<(i32, String)>,
}

impl Routes {
    /// Keeps `route` under a new id (1, 2, …, and 1 again after `i32::MAX`), forgetting the
    /// oldest beyond `KEPT`.
    pub fn add(&mut self, route: String) -> i32 {
        self.last = if self.last == i32::MAX {
            1
        } else {
            self.last + 1
        };
        if self.kept.len() == KEPT {
            self.kept.pop_front();
        }
        self.kept.push_back((self.last, route));
        self.last
    }

    /// The route of notification `id`, while it is one of the last `KEPT`.
    pub fn route(&self, id: i32) -> Option<&str> {
        self.kept
            .iter()
            .find(|(kept, _)| *kept == id)
            .map(|(_, route)| route.as_str())
    }
}

/// What an action on a notification asks for.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Click {
    /// Not a click on the notification itself.
    Ignore,
    /// The window, where it was: the notification is not one of the last `KEPT`.
    Show,
    /// The window, on this route.
    Open(String),
}

/// What the action `action_id` on the notification `id` asks for.
pub fn click(routes: &Routes, action_id: &str, id: Option<i32>) -> Click {
    if action_id != TAP {
        return Click::Ignore;
    }
    match id.and_then(|id| routes.route(id)) {
        Some(route) => Click::Open(route.to_string()),
        None => Click::Show,
    }
}

/// The routes, as the app manages them.
#[derive(Default)]
pub struct NotifyRoutes(Mutex<Routes>);

impl NotifyRoutes {
    fn routes(&self) -> MutexGuard<'_, Routes> {
        self.0.lock().unwrap_or_else(PoisonError::into_inner)
    }
}

/// Keeps the route of a notification about to show, and gives its id; 0 before `listen`.
pub fn remember(app: &AppHandle, route: String) -> i32 {
    app.try_state::<NotifyRoutes>()
        .map_or(0, |routes| routes.routes().add(route))
}

/// Manages the routes and registers the handler of clicks. A refusal is logged: notifications
/// still show, and a click on one does nothing.
pub fn listen(app: &AppHandle) {
    app.manage(NotifyRoutes::default());
    let handle = app.clone();
    let registered = app
        .notification()
        .on_action(move |performed| on_action(&handle, performed));
    if let Err(e) = registered {
        tracing::warn!("a click on a notification will not open Dots: {e}");
    }
}

fn on_action(app: &AppHandle, performed: &ActionPerformed) {
    let id = performed.notification().map(|n| n.id());
    let asked = match app.try_state::<NotifyRoutes>() {
        Some(routes) => click(&routes.routes(), performed.action_id(), id),
        None => click(&Routes::default(), performed.action_id(), id),
    };
    match asked {
        Click::Ignore => {}
        Click::Show => crate::show_main(app),
        Click::Open(route) => {
            crate::show_main(app);
            if let Err(e) = app.emit(NAVIGATE_EVENT, route) {
                tracing::warn!("opening a notification's route failed: {e}");
            }
        }
    }
}
```

```rust
/// The most dots Needs you lists; the Inbox has the rest.
pub const NEEDS_YOU_SHOWN: usize = 10;
/// The one item of Needs you when no dot waits for the person.
pub const NOTHING_WAITING: &str = "Nothing waiting";
/// A dot's item in Needs you has this menu id, followed by the dot's id.
const NEEDS_PREFIX: &str = "needs:";
const NOTHING_ID: &str = "needs-none";

/// The items of Needs you, as (menu id, label): each dot whose needs-you is above 0, as
/// "<dot> (<n>)", most waiting first, then by name, `NEEDS_YOU_SHOWN` at most.
pub fn needs_you_items(rows: &[DotOverview]) -> Vec<(String, String)> {
    let mut waiting: Vec<&DotOverview> = rows.iter().filter(|r| r.needs_you > 0).collect();
    waiting.sort_by(|a, b| {
        b.needs_you
            .cmp(&a.needs_you)
            .then_with(|| a.dot.spec.name.cmp(&b.dot.spec.name))
    });
    waiting
        .into_iter()
        .take(NEEDS_YOU_SHOWN)
        .map(|r| {
            (
                format!("{NEEDS_PREFIX}{}", r.dot.id),
                format!("{} ({})", r.dot.spec.name, r.needs_you),
            )
        })
        .collect()
}

    menu_id

        .map(|dot_id| format!("/home/{dot_id}"))
```

```ts
import { useEffect } from "react";

import { commands } from "@/api/commands";

/// The calls go to the core one after another, so that the last word on what is viewed
/// arrives last: a switch says "none" for the dot left, then names the dot opened.
let queue: Promise<unknown> = Promise.resolve();

/// Queues `call`. A failure shows nothing: the next change sends again (needs-you spec 5).
function send(call: () => Promise<unknown>): void {
  queue = queue.then(call).catch(() => undefined);
}

/// While the conversation of `dotId` is open (an older topic of it counts) and the window is in
/// front, visible and focused, the core is told that the person is viewing the dot and has seen
/// it; when the window goes behind or the conversation closes, that nothing is viewed
/// (needs-you spec section 5). Each change sends again.
export function useViewing(dotId: string): void {
  useEffect(() => {
    let focused = document.hasFocus();
    const update = () => {
      const inFront = focused && document.visibilityState === "visible";
      send(() => commands.setViewing(inFront ? dotId : null));
      if (inFront) send(() => commands.markDotSeen(dotId));
    };
    const onFocus = () => {
      focused = true;
      update();
    };
    const onBlur = () => {
      focused = false;
      update();
    };
    window.addEventListener("focus", onFocus);
    window.addEventListener("blur", onBlur);
    document.addEventListener("visibilitychange", update);
    update();
    return () => {
      window.removeEventListener("focus", onFocus);
      window.removeEventListener("blur", onBlur);
      document.removeEventListener("visibilitychange", update);
      send(() => commands.setViewing(null));
    };
  }, [dotId]);
}
```
