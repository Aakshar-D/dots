
## Install

**Windows**, in PowerShell:

```powershell
irm https://raw.githubusercontent.com/Aakshar-D/dots/master/install.ps1 | iex
```

**Mac**, in Terminal:

```sh
curl -fsSL https://raw.githubusercontent.com/Aakshar-D/dots/master/install.sh | sh
```

Or download the file for your computer below. These installers are not yet signed with a paid certificate, so your browser and your computer ask first:

- Browser says it is not commonly downloaded: choose **Keep**.
- Windows says "Windows protected your PC": choose **More info**, then **Run anyway**.
- Mac says Sage cannot be opened: **System Settings**, **Privacy & Security**, then **Open Anyway**.

Already have Sage? It updates itself.
